# 건축모드 — 대기열과 필요한 공간 확인

시설을 놓을 수 없을 때 **어떤 공간이 필요한지, 어디가 막혔는지, 어떻게 해결할지**를 같은 화면에서 확인하도록 개선했다.

## 화면 구성

| 표시 | 의미 |
| --- | --- |
| 파란 실선 | 시설 본체가 차지하는 바닥 |
| 청록 실선·대기 위치 표식·화살표 | 실제 대기열 경로와 앞줄 방향 |
| 보라 점선 | 관객석과 가장자리 통로가 차지하는 공간 |
| 흰 실선 | 실제 판정에 쓰는 건축구역의 바깥 경계와 내부 빈틈 |
| 주황 실선 | 배치를 막은 대상의 충돌 판정 범위를 바닥에 투영한 표시 |
| 붉은 사선 | 배치를 막는 영역. 겹침·경사 등 정확한 이유는 상태 안내에 표시 |

시설 둘레에 일괄 적용하던 안전 여유 거리는 제거했다. 실제 시설 본체, 대기열, 관람 공간은 계속 확보한다.

선택 중인 시설의 범위는 건물에 가려져도 보인다. 기존 시설의 범위는 월드 깊이를 유지해, 모든 시설 선이 화면 앞으로 나오지 않게 했다. 배치 실패에도 영역별 색은 유지하고 붉은 사선을 추가한다.

범위는 확대·축소에 영향받지 않는 화면 픽셀 두께로 그리며, 어두운 테두리가 밝은 바닥과 선을 구분한다. 격자는 후보 바닥을 안내하며 시설 전체가 들어간다는 보장은 아니다. 선택한 시설 주변의 흰 건축 경계는 G로 격자를 숨겨도 표시한다.

오른쪽 **필요한 공간** 카드는 규격 버튼을 누르지 않아도 보인다.

- 시설 크기를 미터 단위로 표시한다.
- 관객석이 있는 시설은 관객석의 전체 가로·세로와 정원을 별도 보라색 문구로 표시한다. 시설·대기열·관객석 수치는 서로 단순 합산하지 않는다.
- 대기열의 전체 가로·세로 범위, 현재 모양, 대기·이용 정원을 표시한다.
- `7 기본 · 8 좌측 · 9 우측 · 0 U자` 안내는 모양을 변경할 수 있는 시설에 표시한다.
- 대기열 문구 위에 마우스를 올리면 범위의 의미와 동시 이용·이용시간을 확인할 수 있다.
- 도로·타일·조명처럼 대기열이 없는 시설은 `대기열 공간 없음`으로 표시한다.
- 잔액과 확정 후 금액은 **비용 상세**에서 펼쳐 본다.

시설 조합 안내는 왼쪽 위, 필요한 공간은 오른쪽에 배치한다. 조작 안내가 길어지면 조합 카드 아래의 남은 높이에 맞추고 기존 스크롤로 모든 키를 확인할 수 있다.

표시 수치는 남아 있는 빈 공간을 측정한 값이 아니라 **배치에 필요한 크기**다. 대기열 크기는 회전 전 예약 영역 전체의 외접 가로·세로이며, L/U자 내부 빈 공간까지 모두 예약된다는 의미는 아니다. 실제 점유 모양은 바닥의 청록색 표시로 확인한다.

## 배치가 막힐 때

통합 건축구역은 등록된 Gameplay Zone의 정확한 합집합이다. 맞닿거나 겹치는 지역 사이의 내부 선은 배치를 막지 않지만, 어느 지역에도 포함되지 않는 빈틈과 구멍은 건축할 수 없다. 무대 중심이나 본체만 안에 있어서는 충분하지 않으며 대기열과 관객석도 모두 안에 들어가야 한다.

경계 문제는 `관객석 영역이 건축구역 밖으로 나갔어요`처럼 실제로 넘은 대상을 알려 준다. 붉은 표시는 현재 선택한 원인에 맞춘다. 경계 문제를 볼 때는 예약 영역 중 건축구역 밖인 부분만 붉은 사선으로 표시하고, 동시에 존재하는 다른 충돌 때문에 본체 전체를 빨갛게 칠하지 않는다. 여러 문제는 `배치 문제 4개 · 1번째`로 표시하며 **다른 원인**을 누르면 안내와 월드의 붉은 표시가 함께 바뀐다.

1. 상태 안내에서 대기열·관람 공간·시설 겹침 등 원인을 확인한다.
2. 붉은 사선 위치와 겹치는 대상 이름을 확인한다.
3. 대기열은 `7/8/9/0`으로 모양을 바꾸거나 `Q/E`로 시설 방향을 바꾼다. 형태에 따른 기존 정원 조건은 그대로 적용된다.
4. 위치로 해결할 수 있는 문제는 `N` 또는 **가까운 빈자리**로 유효 위치를 찾는다.
5. 미리보기를 확인하고 `Enter` 또는 **배치 확정**으로 설치한다.

표시를 위해 충돌 조건이나 대기 정원을 완화하지 않는다. 빈자리 찾기와 대기열 형태 미리보기만으로 시설 설치나 비용 차감이 발생하지 않는다.

### 바닥을 장애물로 오인하는 경우와 겹침 표시

일반 시설도 설치 바닥을 샘플링한 결과를 충돌 검사에 사용한다. 허용 경사와 높이 차, 필요한 샘플 조건을 만족한 지면만 바닥으로 인정하며, 그 지면 위 공간을 다시 검사한다. 대기열·관객석은 각 영역의 바닥을 별도로 확인한다. 별도 소품이나 지면 위로 솟은 충돌체가 자동으로 무시되는 것은 아니다.

빈 땅이어도 관객석이나 대기열의 바닥 경사·높이 차·지지 조건을 넘으면 배치할 수 없다. 이때는 `관객석 바닥 높이 차가 너무 커요`처럼 해당 영역과 바닥 원인을 표시하고, 측정값과 허용값을 함께 안내한다. 붉은 사선은 문제가 있는 관객석·대기열에만 표시하며, 지형 전체를 주황색 장애물로 표시하지 않는다. 같은 영역에 실제 장애물도 있으면 주황 선과 장애물 안내를 함께 유지한다.

겹침이 남아 있으면 현재 선택한 원인의 장애물 이름과 **주황 선 / 붉은 사선**을 함께 확인한다. 월드 장애물도 가능한 경우 액터 이름과 메시 이름을 표시한다. 주황 선은 충돌 판정에 쓰인 외접 범위를 바닥 높이에 투영한 것이며, 실제 메시 윤곽이나 정밀 접촉면을 뜻하지 않는다. 맵 전체를 덮는 큰 충돌체는 필요한 공간에서 주변 2m까지 잘라 표시하므로, 주황 선의 바깥 끝이 물체 전체의 끝은 아닐 수 있다.

붉은 사선은 해당 외접 범위와 현재 필요한 공간이 겹치는 부분에만 표시한다. 작은 장애물 때문에 시설 바닥 전체를 사선으로 덮지 않는다. 겹친 부분이 사각형일 때는 반투명 붉은 면도 그 부분만 덮고, 다른 모양은 잘린 사선으로 표시한다. 높거나 땅속에 있는 충돌체도 배치 바닥 위의 선으로 확인할 수 있으며, **다른 원인**을 선택하면 안내와 표시가 함께 바뀐다.

제작 시 BoundarySpline 컴포넌트의 상대 이동·회전·크기도 실제 경계 계산에 반영한다. 실행 중 지역 경계를 직접 편집했다면 기존 `RefreshBuildArea` 또는 **Rebuild From World Regions** 갱신 경로를 호출해야 한다. 흰 경계와 붉은 사선은 최종 판정과 동일한 통합 경계 캐시를 사용한다.

통합 연산에서 생길 수 있는 면적 없는 왕복 접합선은 경계 캐시 생성 시 제거한다. 같은 접점을 반복해서 지나가는 경계는 실제 외곽과 구멍으로 분리한다. 실제 구멍과 오목한 경계는 보존하면서, 내부 접합선 때문에 정상적인 땅을 건축구역 밖으로 오판하는 경우를 막는다.

## 적용과 검증

실행 코드와 `WBP_FF_BuildTools`에 적용한다. 에디터 제작 명령은 `FF.ApplyBuildPlacementSpace`이며, `Tools/Build/apply_placement_space_ui.py`가 변경 전 WBP 백업, 기존 위젯 보존, 다른 UI 파일 불변, 재실행 시 파일 불변을 확인한다.

검증 결과와 이미지는 `Saved/PlacementSpace/` 및 `Saved/Automation/BuildableGrid/`에 기록한다. 화면 검증은 실제 저장된 WBP를 1280×720과 1920×1080으로 렌더링하며, 수동 플레이 조작 검증과는 구분한다.

다음은 안전 여유 제거 전 배치 공간 표시 개선의 2026-10-07 확인 기록이다. 연결된 이미지는 당시 UI이며 현재 안전 여유 수치·범례는 표시하지 않는다.

- Development Editor 빌드 성공.
- 범위 경로·깊이, 대기열 형태, 필요한 공간 수치, 배치 도움, 조합 패널과 UI 계약 등 **자동화 테스트 24개 통과**. 픽셀 두께 표시와 도움말 영역 조정 후 최종 빌드에서 전체 재확인했다.

### 빈 잔디의 충돌 오판 및 장애물 표시 검증 — 2026-10-07

- `Test_Main`의 메인공연장 위치 `(78800.5, 42200.5, 416.863605)`에서 빈 잔디가 `PlacementCollision`으로 거절되는 문제를 재현했다. 실제 대상은 나무가 아니라 `Landscape_0.LandscapeHeightfieldCollisionComponent_85`였다. 일반 시설은 지면 검증 증거를 충돌 검사에 전달하지 않아, 평균 바닥 높이보다 높은 완만한 지면 부분을 장애물로 오인했다.
