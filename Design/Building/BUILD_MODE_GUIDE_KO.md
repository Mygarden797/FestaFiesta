# 빈 공간을 보면서 만드는 건축 모드

건축 모드의 격자는 **바닥 위에 펼친 모눈종이**처럼 생각하면 됩니다. 건축에 쓸 수 있는 빈 공간에만 선을 보여 주고, 다른 시설과 통행로가 차지한 곳에서는 선을 지웁니다. 시설을 고르기 전에도 주변 공간을 살펴보고, **시설을 배치하거나 옮기는 동안에도 같은 전체 주변 격자를 보면서** 배치를 맞출 수 있습니다.

심즈 4의 건축 모드에서 참고한 방향은 공간을 보며 배치하고, 정렬을 쉽게 맞추고, 필요하면 자유롭게 미세 조정하는 조작감입니다. 이 프로젝트에서는 기존 축제 시설·구역·입구·대기 줄 규칙에 맞춰 적용했습니다. 준비 시간에는 건축 실행 취소·다시 실행, 그룹 편집과 배치 프리셋, 시설별 대기열 형태 선택을 지원합니다. 자세한 조작은 [건축 편집 확장 사용 가이드](ConstructionEditing_UserGuide_KO.md)를 참고하세요. 벽·방 생성 기능은 포함하지 않습니다.

[사용자가 제공한 T.O.O.L / Better Build Buy 소개 영상](https://www.youtube.com/watch?v=5c8LCwsO1wQ)의 도구 창과 세밀한 이동 조작도 참고했습니다. 프로젝트에 맞는 기능으로 숫자 각도 입력, 선택 간격을 유지하는 정렬 버튼, 방향별 미세 이동을 적용했습니다.

## 화면을 읽는 방법

| 화면 표시 | 뜻 | 사용 방법 |
|---|---|---|
| 바닥의 격자 | 주변에서 건축에 쓸 수 있는 빈 공간 | 시설끼리 줄을 맞추거나 간격을 잡습니다. |
| 주변 격자가 중간에서 끊기는 곳 | 구역 밖, 기존 시설의 사용 공간, 보호된 통행로, 지면이 없거나 너무 가파른 곳 등 | 선이 있는 쪽으로 옮깁니다. 선택한 시설을 허용하지 않는 구역도 격자를 표시하지 않습니다. |
| 시설 미리보기의 초록 표시 | 현재 시설 전체를 놓을 수 있다는 미리보기 결과 | 입구 방향과 대기 공간까지 확인한 뒤 확정합니다. |
| 시설 미리보기의 빨강 표시 | 시설 전체를 현재 위치에 놓을 수 없음 | 위치·회전을 바꿉니다. 확정을 시도하면 기존 안내가 실패 이유를 알려 줍니다. |

격자 한 칸에 여유가 있다고 큰 시설 전체가 들어가는 것은 아닙니다. **격자는 빈 바닥을, 초록·빨강은 선택한 시설 전체의 결과를 알려 줍니다.** 입구·대기 줄·지형·동선·설치 비용·건축 한도까지 확인하며, 실제로 설치하는 순간에도 같은 건축 규칙을 다시 검사합니다.

격자는 카메라 주변에 필요한 범위만 표시합니다. 먼 곳은 카메라를 옮겨 확인하세요. 시설을 선택해도 주변 격자가 사라지지 않으며, 선택한 시설을 놓을 수 있는 구역의 빈 공간을 계속 보여 줍니다. 이동 중인 시설이 원래 차지하던 자리도 이동 후보 공간으로 확인할 수 있습니다. 새로운 공간은 바닥을 확인한 부분부터 격자가 나타납니다. `G`로 격자를 숨긴 상태에서는 선이 없어도 건축 금지라는 뜻이 아닙니다. `G`를 다시 누르면 공간 안내가 돌아옵니다.

## 편하게 배치하는 순서

1. 준비 시간에 건축 탭이나 `B`로 시설 목록을 엽니다. 목록을 접어 주변의 빈 건축 공간을 먼저 살펴볼 수도 있습니다.
2. 원하는 시설을 선택하고 격자가 있는 쪽으로 옮깁니다. 기본적으로 1m 간격으로 맞춰져 여러 시설을 가지런히 놓기 쉽습니다.
3. `Q/E`로 방향을 돌립니다. 더 부드럽게 맞추려면 `Shift`와 `Q/E`를 함께 누릅니다.
4. 조금만 옮길 때는 `Ctrl`, 자유롭게 미세 조정할 때는 `Alt`를 누른 채 마우스를 움직입니다. 키를 놓으면 건축 도구에서 선택한 기본 간격으로 돌아옵니다.
5. 시설의 초록 표시를 확인하고 좌클릭이나 `Enter`로 설치합니다. 같은 시설이 계속 따라오기 때문에 다시 목록을 열지 않고 연속으로 놓을 수 있습니다.
6. 우클릭으로 목록에 돌아갑니다. 기존 시설을 옮길 때 우클릭하면 이동만 취소하고 원래 자리를 유지합니다.

## 새 시설 목록 사용하기

하단의 **축제 만들기** 화면은 물건을 고르는 게임 상점처럼 읽으면 됩니다. 왼쪽에서 부스·휴게·공연 같은 큰 분류를 고르고, 오른쪽 위에서 먹거리·상품 판매·공예 체험 같은 세부 종류를 고릅니다. 카드에서는 `부스 > 상품 판매`와 `FestivalGoods`처럼 분류와 고유 이름을 따로 확인할 수 있습니다. 검색창은 시설 이름뿐 아니라 한글 분류 이름으로도 찾습니다.

시설 이미지를 크게 두고 가격, 설치 수량, 선택할 수 없는 이유를 서로 다른 줄에 표시했습니다. 긴 이름은 카드 안에서 줄임표로 정리하며, 마우스를 올리면 전체 이름과 분류를 확인할 수 있습니다. 돈이 부족하거나 설치 한도에 도달한 카드는 안내 문구를 함께 보여 줍니다.

목록을 스크롤해도 카드는 같은 크기를 유지합니다. 원본 이미지가 크거나 세로로 길어도 카드가 늘거나 줄지 않으며, 가격·이미지가 바뀔 때 보이는 카드를 지웠다가 다시 만들지 않습니다. 화면 밖의 카드는 재사용하므로 시설 종류가 많아져도 모든 카드를 한꺼번에 생성하지 않습니다.

디자이너에서 수정할 화면은 `WBP_FF_PrepPanelBuild`(목록), `WBP_FF_PrepBuildTile`(카드), `WBP_FF_BuildCategoryChoice`(분류 버튼), `WBP_FF_FacilityInfoPanel`(배치한 시설 정보)입니다. 공통 프로젝트 팔레트의 밝은 바탕·진한 청록·상태 색을 함께 사용합니다.

카드의 바깥 크기(170×164)와 이미지가 들어가는 틀(150×70)은 스크롤 안정성을 위해 `FFPrepBuildTileLayout` 한 곳의 수치를 사용합니다. 카드 크기 자체를 바꿀 때는 이 수치와 화면 높이를 함께 확인하고, 글자·색·카드 안의 배치는 UMG Designer에서 편집합니다.

개발용 `FF.RefreshBuildStudioUMG`는 목록과 카드의 기본 디자인을 명시적으로 다시 저장합니다. 기존 배치 중의 얇은 안내 띠는 그대로 복사해 보존합니다. `FF.RefreshFacilityInfoGameUMG`는 시설 정보창을 다시 저장합니다. 이미 제공된 WBP를 사용하는 일반 플레이에는 두 명령을 실행할 필요가 없습니다.

## 배치한 시설의 정보 확인

시설 확인 모드에서 기존 시설을 클릭하면 이름·상태·비용 등 기존 시설 정보창이 열립니다. 시설 목록을 펼친 상태에서도 화면 속 시설을 클릭할 수 있으며, 이때 목록이 접히고 해당 시설의 정보가 나타납니다. 목록의 카드·검색창·버튼을 누르는 클릭은 뒤쪽 시설로 전달되지 않습니다.

다른 시설을 클릭하면 정보가 바뀌고, 같은 시설을 다시 눌러도 조회만 합니다. 빈 바닥이나 우클릭으로 선택을 해제할 수 있습니다. 정보 조회는 시설의 위치나 개수, 잔액을 바꾸지 않습니다. 새 시설이 마우스를 따라오는 배치 중에는 목록으로 돌아가거나 목록을 접어 시설 확인 모드로 전환한 뒤 기존 시설을 선택하세요.

## 마우스로 사용하는 건축 도구

단축키를 외우지 않아도 건축 전용 도구에서 격자와 배치 간격을 선택하고, 회전과 미세 이동을 할 수 있습니다. 격자 표시와 간격 선택은 시설을 고르기 전에도 사용할 수 있고, 회전·각도·미세 이동은 시설을 배치하거나 옮기는 동안 사용할 수 있습니다.

시설 목록을 펼친 동안에는 목록이 아래 공간을 사용합니다. 목록을 접거나 시설을 선택하면 작은 건축 도구창이 나타나며, 목록을 가리지 않습니다.

| 도구 | 사용 방법 |
|---|---|
| 설치 / 이동 확정 | 도구로 맞춘 위치와 각도를 그대로 확정합니다. 미세 이동 후에는 마우스를 바닥으로 되돌리지 않고 이 버튼을 누르세요. |
| 격자 켜짐/꺼짐 | 현재 표시 상태를 확인하고 클릭해 바꿉니다. `G`와 같은 동작입니다. |
| 1m / 25cm / 자유 | 계속 사용할 위치 맞춤 간격을 선택합니다. 자유는 1cm 단위입니다. `Ctrl`이나 `Alt`를 계속 누르고 있을 필요가 없습니다. |
| 좌우 회전 | 한 번 누를 때마다 45°씩 회전합니다. |
| 각도 입력 | `22.5`처럼 0~360° 범위의 각도를 직접 입력합니다. Enter 또는 설치 버튼으로 적용합니다. 360°는 0°와 같은 방향이며 소수 둘째 자리까지 반영합니다. |
| 방향별 미세 이동 | 선택한 간격만큼 구역 격자의 가로·세로 방향으로 한 번 움직입니다. 1cm 간격을 선택하면 더 섬세하게 조절할 수 있습니다. |

도구 위에서 클릭하거나 각도를 입력하는 동작이 바닥의 시설 설치로 전달되지 않게 처리합니다. 도구에서 조절한 위치와 방향도 기존 배치 검사에 따라 초록·빨강 표시가 갱신됩니다.

새 화면은 `/Game/FestaFiesta/Building/FF_WBP_Building/Controls/WBP_FF_BuildTools`입니다. UMG Designer에서 위치·글꼴·색·간격을 편집할 수 있습니다. 연결된 버튼과 입력창 이름은 유지하세요. 기존 프로젝트의 밝은 종이색·청록색 팔레트를 사용해 다른 UI와 톤을 맞췄습니다. 새 환경에서 에셋이 누락된 경우에만 에디터 콘솔 명령 `FF.BuildToolsUMG`로 생성하며, 이미 있는 WBP 디자인은 덮어쓰지 않습니다.

## 조작표

아래 숫자는 프로젝트의 기본값이며 담당자가 Project Settings에서 조정할 수 있습니다.

| 조작 | 동작 |
|---|---|
| `B` | 시설 목록 열기/접기. 배치·이동 중이면 목록으로 돌아갑니다. |
| 좌클릭 / `Enter` | 새 시설 설치 또는 현재 이동 확정. 새 시설은 설치 후 연속 배치합니다. |
| `Q/E` | 배치 중에는 45°씩 시설 회전. 시설을 배치하지 않을 때는 카메라 회전입니다. |
| `Shift + Q/E` | 누르는 동안 시설을 부드럽게 회전합니다. |
| `Ctrl` 유지 | 25cm 간격으로 정밀하게 위치를 맞춥니다. |
| `Alt` 유지 | 1cm 간격으로 자유롭게 위치를 맞춥니다. `Ctrl`과 함께 누르면 `Alt`가 우선합니다. |
| `G` | 건축 세션에서 격자 표시/숨기기. `Ctrl+G`는 기존 개발용 패널 단축키입니다. |
| 우클릭 | 새 배치 중에는 목록 복귀, 이동 중에는 이동 취소, 시설 선택 중에는 선택 취소입니다. |
| `WASD` | 카메라 이동. |
| `ESC/F5` | 일시정지·옵션. |

`Alt`는 충돌이나 구역 제한을 무시하는 기능이 아닙니다. 위치를 세밀하게 조절하는 기능이며 실제 건축 규칙은 그대로 적용됩니다. 격자를 숨겨도 자동 정렬과 배치 검사는 유지됩니다. 1cm 자유 배치에서 바닥까지 1cm 격자로 채우지는 않아 화면이 복잡해지지 않습니다.

## 유지보수와 성능을 위한 구조

쉽게 말하면 **건축 규칙표는 하나만 두고, 화면은 그 규칙표에서 필요한 부분을 읽어 그립니다.** 화면 전용으로 다른 규칙을 만들면 “가능하다고 보여 줬는데 실제로는 안 되는” 문제가 늘어나기 때문입니다.

| 담당 코드 | 역할 |
|---|---|
| `UFFZSWorldSubsystem` | 구역 경계·보호 동선·기존 시설 사용 공간을 바탕으로 표시 가능한 공간을 제공합니다. 실제 건축 확정의 규칙도 이 시스템이 소유합니다. |
| `AFFZSPlacementPreviewActor` / `AFFZSBuildableGridActor` | 시설 미리보기와 건축 세션 전체의 주변 격자를 각각 관리합니다. 배치·이동 중에도 전체 격자를 유지하며 선을 이중으로 그리지 않습니다. |
| `UFFZSBuildableGridComponent` | 공간 안내를 저장해 재사용하고, 지형에 맞춘 선을 묶어서 그립니다. |
| `FFFZSBuildGridSurfaceCache` | 바닥의 실제 높이·경사·높이 차이를 조금씩 확인하고 결과를 재사용합니다. 지면이 없거나 아직 확인하지 못한 칸은 숨깁니다. |
| `UFF_BuildModeSubsystem` | 건축 시작/종료, 목록/배치/이동 전환, 입력과 격자 수명을 관리합니다. |
| `UFF_BuildModeGuide` | 격자 의미와 조작법을 설명합니다. 가격·점유·건축 가능 여부를 독자적으로 판정하지 않습니다. |
| `UFF_BuildToolsWidget` | 건축 전용 버튼·각도 입력을 제공하고, 기존 서브시스템의 배치 명령을 호출합니다. |
| `UFF_PrepPanelBuild` / `UFF_PrepBuildPresentationModel` | 대분류·소분류·검색 조건을 적용하고, 원본 시설과 비용 데이터를 화면에 투영합니다. |
| `UFF_PrepBuildTileView` / `UFF_PrepBuildTileWidget` | 화면에 필요한 카드만 재사용하며 고정 크기로 표시합니다. 이미지 해상도와 카드 크기를 분리합니다. |

격자의 작은 칸마다 별도 건물이나 위젯을 만들지 않습니다. 주변 표시 범위를 제한하고 선을 묶어서 그립니다. 막힌 구역은 색만 바꾸는 대신 실제로 표시할 선에서 제외합니다. 정확한 배치 판정은 시설 전체를 대상으로 수행해, 안내 격자 때문에 배치 검사 비용이 칸 수만큼 늘어나지 않게 합니다.

격자선은 실제 게임의 렌더링 경로를 사용하며, 화면의 픽셀 기준으로 두께를 유지합니다. 카메라가 멀어졌다는 이유로 선이 너무 얇아져 끊겨 보이는 현상을 줄입니다. 경계는 더 굵고 밝게 표시하고 바깥쪽 선은 단계적으로 옅어집니다.

바닥 확인은 칸이 공유하는 꼭짓점 결과를 재사용하며 한 번에 최대 512번만 수행합니다. 중심부터 확인해 가까운 공간이 먼저 나타나고, 계속 이동해도 현재 표시 범위 밖의 기록은 정리합니다. 큰 표시 범위는 검사 예산에 맞춰 기록의 유지 시간을 늘리고, 유효 시간이 끝나기 전에 나누어 재확인합니다. 오래되어 유효하지 않은 기록으로 바닥이 있다고 표시하지 않습니다.

주변에 여러 구역이 보이면 지면 검사 예산을 구역끼리 나누어 사용합니다. 시설을 찾는 반복 조회도 저장된 결과를 재사용하고, 시설이 바뀌거나 갱신 시간이 되면 다시 확인합니다.

장애물 후보는 주변에서 한 번에 모은 뒤 실제 바닥 높이에 맞춰 걸러냅니다. 완만하게 기울어진 메시 바닥을 건물 장애물로 잘못 취급하지 않도록, 네 모서리를 받치는 바닥과 장애물을 구별합니다. 보호 통행로는 설치 검사가 쓰는 구역 기준 높이를 따라 확인하므로 카메라가 높은 물체를 바라봐도 사라지지 않습니다.

기존 건축 가이드 WBP는 다시 저장하지 않아도 이름이 맞는 텍스트 행을 갱신합니다. `TXT_GuideRow_0`~`4`가 이 가이드의 표시 계약입니다. UI 개편은 Asera 작업 이력이 확인된 건축 목록·카드·시설 정보 파일과 새 건축 전용 파일에서 수행합니다. 다른 준비 탭의 화면은 편집 대상에 포함하지 않습니다.

### 담당자가 조정하는 곳

Unreal Editor의 **Project Settings → Game → FF Zone System**에서 다음 값을 조절합니다. 표시 크기와 건축 규칙은 다른 설정입니다.

| 설정 | 뜻 |
|---|---|
| `PlacementPositionSnapCm` | 평소 위치 맞춤 간격. 기본 100cm. |
| `PrecisionPlacementPositionSnapCm` | `Ctrl` 위치 맞춤 간격. 기본 25cm. |
| `FreePlacementPositionSnapCm` | `Alt` 위치 맞춤 간격. 기본 1cm. |
| `PlacementRotationSnapDegrees` | `Q/E` 한 번의 회전 각도. 기본 45°. |
| `PlacementGridPaddingCm` | 선택한 시설 주변에 추가로 보여 줄 격자 여백. |
| `PlacementGridMaxRadiusCm` | 주변 격자 표시 반경의 제한. |
| `PlacementGridMajorIntervalCm` | 굵은 기준선 간격. |
| `PlacementGridSurfaceLiftCm` | 바닥과 격자가 겹쳐 깜빡이지 않게 살짝 띄우는 높이. |

시설이 사용하는 면적은 시설의 footprint·여유 공간·대기 줄 설정으로, 건축 구역과 보호 통행로는 Zone 데이터로 관리합니다. 예외 구역을 추가할 때 화면에서만 격자를 가리는 코드를 붙이지 말고 해당 공간을 소유하는 데이터에 등록해야 실제 설치 검사와 함께 유지됩니다.

## 에디터에서 확인할 항목

1. 빈 구역에서 목록을 열고 닫아도 주변 격자가 보이고, 건축을 종료하면 사라지는지 확인합니다.
2. 경계 밖·기존 시설·대기 줄·보호 동선에 격자가 남지 않는지 확인합니다.
3. 시설 종류를 바꿀 때 허용되지 않는 구역의 격자가 사라지는지 확인합니다.
4. 시설 설치·이동·철거 후 새로 막힌 곳과 비어진 곳이 갱신되는지 확인합니다. 이동 중인 시설의 기존 공간이 자기 자신 때문에 막히지 않는지도 확인합니다.
5. `Ctrl/Alt`, `Shift+Q/E`, 연속 설치, 우클릭 취소, `G` 표시 전환과 건축 도구의 간격·각도·미세 이동을 확인합니다. 도구 클릭이나 각도 입력으로 시설이 의도치 않게 설치되지 않는지 확인합니다.
6. 격자가 있는 좁은 공간에 큰 시설을 가져가면 빨강으로 거절되는지, 잔액 부족·잘못된 운영 단계 등 기존 실패 안내가 유지되는지 확인합니다.
7. 지형 구멍과 급경사에는 선이 생기지 않는지, 넓은 평지에서 격자가 주기적으로 사라지는 현상이 없는지 확인합니다.

이 목록은 수동 확인 절차입니다. 실행 결과와 자동화 테스트 결과는 실제로 수행한 검증 보고를 기준으로 판단합니다.
