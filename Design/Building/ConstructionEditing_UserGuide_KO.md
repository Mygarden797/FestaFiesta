# 건축 편집 사용 가이드 — 실수 복구·그룹 배치·대기열

준비 시간에 축제장을 꾸밀 때 쓰는 기능입니다. **실수한 배치를 되돌리고, 여러 시설을 한 묶음으로 옮기고, 시설마다 줄 서는 방향을 바꿀 수 있습니다.** 프로그래밍이나 Unreal 에디터 설정 없이 게임의 건축 화면에서 사용합니다.

## 시작하기

1. 최초 준비 또는 아침 점검 시간에 건축 모드를 엽니다. 기존 `B` 키로 시설 목록을 열 수 있습니다.
2. 이미 놓은 시설을 다루려면 시설 목록에서 일반 건축 화면으로 돌아옵니다.
3. 손님이 이용 중인 시설은 먼저 운영을 닫고 손님이 모두 나갈 때까지 기다립니다.

운영 중에는 편집할 수 없습니다. 빨간 안내가 나오면 이유를 읽고 위치나 방향을 바꾸세요. 명령이 거절되면 기존 시설과 자금은 그대로 남습니다.

## 1. 실수한 작업 되돌리기

| 하고 싶은 일 | 조작 |
| --- | --- |
| 방금 확정한 건축 작업 취소 | **조작 안내 → 실행 취소** 또는 `Ctrl+Z` |
| 취소한 작업 다시 적용 | **조작 안내 → 다시 실행** 또는 `Ctrl+Y`, `Ctrl+Shift+Z` |
| 아직 확정하지 않은 이동 미리보기 취소 | 마우스 오른쪽 버튼 |

상단 메뉴의 **조작 안내**를 열면 실행 취소와 다시 실행 항목이 함께 나옵니다. 별도의 건축 편집 패널은 사용하지 않습니다. 설치, 이동·회전, 철거, 그룹 편집, 대기열 형태 변경을 되돌릴 수 있습니다. 이름이나 각도를 입력하는 칸에서 `Ctrl+Z`를 누르면 글자 편집을 방해하지 않습니다.

예를 들어 700 Gold 시설을 설치했다가 실행 취소하면 해당 설치비 700 Gold가 돌아옵니다. 일반 철거의 일부 환급과 다릅니다. 철거를 취소하면 시설을 복구하면서 **실제 받았던 철거 환급액**을 회수합니다. 당시 환급액을 이미 써버렸다면 자금이 부족해 취소할 수 있습니다. 직원 고용 등 다른 작업에서 쓴 돈은 함께 되돌리지 않습니다.

그룹으로 확정한 작업은 실행 취소 한 번으로 함께 복구됩니다. 취소한 뒤 새로운 건축 작업을 확정하면 이전 다시 실행 목록은 지워집니다. 최근 64개 작업을 보관하며, 운영 단계 전환·저장 불러오기 등으로 기록이 초기화됩니다. 기록은 게임을 종료한 뒤까지 보관하지 않습니다.

## 2. 여러 시설을 함께 이동·회전·철거·복제하기

**그룹**은 함께 선택한 시설 묶음입니다. 시설 사이의 간격을 유지하므로 먹거리 부스 여러 개를 하나씩 옮길 필요가 없습니다.

1. 건축 화면에서 **다중 선택**을 누릅니다.
2. 시설을 하나씩 클릭하거나 마우스로 사각형을 그려 여러 시설을 선택합니다. 선택된 시설을 다시 클릭하면 선택이 해제됩니다.
3. 아래 선택 도구에서 **묶음 이동**을 누르고, 놓을 곳을 가리킵니다.
4. `Q`와 `E`로 묶음 전체를 회전합니다. 시설들의 가운데를 기준으로 함께 돌아갑니다.
5. 배치 가능한 위치에서 왼쪽 클릭 또는 `Enter`로 확정합니다. 오른쪽 클릭으로 취소합니다.

| 기능 | 결과 | 자금 |
| --- | --- | --- |
| 그룹 이동·회전 | 원래 시설의 간격과 개별 상태를 유지하며 새 위치로 이동 | 설치비 없음 |
| 그룹 철거 | 선택한 시설을 함께 제거 | 시설별 철거 환급 적용 |
| 그룹 복제 | 기존 시설을 남기고 새 시설 묶음 설치 | 새 시설 전체 설치비 필요 |

전체가 유효할 때만 확정합니다. 한 시설이라도 건설 영역 밖이거나 다른 시설·대기 공간·보호 통로와 겹치거나 자금·건축 한도가 부족하면 전부 거절됩니다. 한 번에 최대 128개 시설을 처리합니다.

복제는 새 시설을 구매하는 기능입니다. 배치와 대기열 형태를 복사하며, 기존 시설의 강화 등급을 무료로 복제하지 않습니다.

### ‘먹거리 거리’ 같은 배치 프리셋 저장하기

**프리셋**은 재사용할 수 있는 배치 설계도입니다. 시설 배치 간격·방향과 대기열 형태를 기억합니다.

1. 완성한 구성을 다중 선택합니다.
2. 이름 칸에 `먹거리 거리` 또는 `휴게 공간`처럼 알아보기 쉬운 이름을 입력합니다.
3. **이름으로 저장**을 누릅니다.
4. 나중에 다중 선택 도구의 저장 목록에서 이름을 고르고 **불러와 배치**를 누릅니다.
5. 땅을 가리켜 위치를 정하고 회전한 뒤 확정합니다. 새 시설을 설치하므로 설치비가 필요합니다.

프리셋은 게임을 다시 실행해도 남습니다. 최대 32개, 이름은 1~40자입니다. 같은 이름으로 저장하면 그 설계도를 덮어씁니다. 프리셋을 삭제해도 이미 설치한 시설은 사라지지 않습니다. 저장 공간 문제로 저장에 실패하면 안내가 표시됩니다.

## 3. 시설마다 줄 서는 방향 바꾸기

키보드 **윗줄의 숫자 키**를 사용합니다. 키보드 오른쪽 숫자패드가 아닙니다. 다중 선택 중에는 시설별 대기열을 바꾸지 않습니다.

| 키 | 형태 | 의미 |
| --- | --- | --- |
| `7` | 기본형 | 제작자가 시설에 지정한 원래 대기열 |
| `8` | 좌측형 | 시설 자체의 방향을 기준으로 왼쪽으로 뻗는 줄 |
| `9` | 우측형 | 시설 자체의 방향을 기준으로 오른쪽으로 뻗는 줄 |
| `0` | U자형 | 줄을 접어 돌아오는 형태. 대기 자리가 최소 4개여야 함 |

**새 시설을 배치할 때:** 시설을 고른 뒤 땅을 가리킨 상태에서 `7`·`8`·`9`·`0` 중 하나를 누릅니다. 미리보기의 줄 모양이 바뀌므로 주변 공간을 보면서 선택하고 배치를 확정하세요. 조작 안내에서 현재 형태도 확인할 수 있습니다.

**이미 놓은 시설을 바꿀 때:** 준비 시간의 일반 건축 화면에서 시설 하나를 클릭한 다음 `7`·`8`·`9`·`0` 중 하나를 누릅니다. 공간과 통로 검사를 통과하면 즉시 적용됩니다. 실패하면 이유를 표시하고 기존 형태를 유지합니다. `Ctrl+Z`로 되돌리거나 `7`로 기본형을 선택할 수 있습니다.

**시설을 이동할 때:** 이동 미리보기 중에도 `7`·`8`·`9`·`0`으로 형태를 바꿀 수 있습니다. 이동을 확정하면 위치와 줄 모양이 함께 적용되며, 실행 취소 한 번으로 함께 되돌립니다. 확정 전에 오른쪽 클릭으로 취소하면 원래 위치와 줄 모양을 유지합니다.

이름이나 각도 입력 칸에 글자를 입력하는 중이거나 일시 정지 메뉴가 열려 있으면 숫자 키로 대기열을 변경하지 않습니다.

화면 왼쪽·오른쪽 기준이 아닙니다. 시설을 회전하면 줄도 시설과 함께 회전합니다. 줄 모양을 바꿔도 수용 인원을 늘리는 기능은 아닙니다. 대기열이 없는 조명·도로·바닥 시설에는 형태 선택이 표시되지 않습니다. 시설의 공간 조건에 맞지 않는 형태는 거절됩니다.

시설 본체, 최대 대기 공간, 입구·출구, 다른 시설과의 겹침, 보호된 통로와 설정된 NPC 이동 경로를 함께 검사합니다. 빈 땅처럼 보여도 줄의 폭과 손님 통로가 들어갈 수 없으면 거절될 수 있습니다. 형태 선택은 시설 저장 데이터에 포함되며 복제와 프리셋에서도 유지됩니다.

## 막혔을 때 확인할 것

| 상황 | 확인할 것 |
| --- | --- |
| 실행 취소 버튼이 꺼져 있음 | 취소할 기록이 있는지, 준비 시간인지 확인합니다. |
| 철거 취소가 자금 부족으로 실패 | 철거로 받은 돈을 다시 회수할 수 있을 만큼 잔액을 확보합니다. |
| 그룹 일부가 안 들어감 | 묶음 전체가 들어갈 공간으로 옮기거나 선택에서 일부를 뺍니다. |
| 프리셋 배치가 거절됨 | 전체 설치비·시설별 건축 한도·현재 시설 데이터·땅의 공간을 확인합니다. |
| 대기열 변경이 거절됨 | 시설 운영을 닫고 손님이 나갔는지, 줄과 통로 공간이 있는지 확인합니다. |
| 저장을 불러왔더니 실행 취소 목록이 없음 | 정상입니다. 배치와 대기열 설정은 저장하지만 작업 이력은 현재 준비 세션용입니다. |

## 화면 디자인을 바꾸는 방법 — Unreal 에디터

다중 선택 화면은 **UMG의 WBP(화면 설계 파일)** 로 저장되어 있습니다. C++ 코드를 고치지 않아도 버튼 색, 글꼴, 여백, 크기와 배치를 Designer에서 바꿀 수 있습니다.

1. 콘텐츠 브라우저에서 `Content/FestaFiesta/Building/FF_WBP_Building/Controls` 폴더를 엽니다.
2. **`WBP_FF_BuildMultiSelection`** 을 열고 **Designer** 탭을 선택합니다. 다중 선택 제목, 작업 버튼, 프리셋 입력 칸과 목록을 수정할 수 있습니다.
3. 선택된 시설 하나의 카드 모양은 **`WBP_FF_BuildSelectedFacilityCard`** 에서 수정합니다. 카드의 시설 이름·이미지는 게임에서 자동으로 채웁니다.
4. 기존 조작 안내와 상단 메뉴는 **`WBP_FF_BuildTools`** 에서 수정합니다. 시설+를 포함한 상단 아이콘도 선과 도형으로 구성된 UMG 요소입니다.
5. 수정 뒤 **Compile → Save** 를 누르고 플레이 화면에서 확인합니다.

기능 연결에 쓰는 기존 위젯 이름은 유지하세요. 예를 들어 `Button_MoveGroup`, `Edit_PresetName`, `Combo_Presets`의 이름을 바꾸면 자동 연결이 끊길 수 있습니다. 글자·색·위치·크기는 바꿔도 됩니다. 저장된 WBP의 스타일을 게임 실행 때 코드가 다시 덮어쓰지 않습니다.
