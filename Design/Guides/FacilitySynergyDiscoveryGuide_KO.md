# 시설 조합 100개와 최초 발견 보상

수정일: 2026-09-21

시설 조합은 총 100개입니다. 기존 22개 조합의 이름·ID·거리·수익 보너스를 유지하고 78개를 추가했습니다. 일반 이용 수익이 있는 부스 31종 모두에 조합이 있으며, 초기 최초 발견 보상은 조합마다 **100 Gold**입니다.

## 발견 보상 바꾸기

1. 최신 Editor 빌드를 적용한 뒤 게임 실행을 정지합니다.
2. Content Drawer에서 `FestaFiesta > Data > Economy > DT_FacilitySynergies`를 엽니다.
3. 바꿀 조합 행을 선택합니다.
4. Row Editor의 **최초 발견 보상 (골드)**을 수정합니다. 내부 열 이름은 `DiscoveryRewardGold`입니다.
5. **Ctrl+S**로 저장하고 게임을 다시 실행합니다. 조합표는 게임 시작 시 읽습니다.

예를 들어 `BurgerPicnic` 행에 250을 입력하면 그 조합을 발견한 뒤 도감 카드의 **선물 아이콘**을 눌러 250 Gold를 받습니다. **0은 보상 없음**이며 조합 발견 자체는 유지됩니다. 음수는 유효하지 않습니다. 보상에는 수수료·시설 강화·조합 수익 배율을 곱하지 않습니다.

## 도감에서 시설 확인과 보상 수령

- 도감은 화면 전체로 열립니다. 넓은 화면에서는 오른쪽 상세 패널에서 선택한 조합을 확인하며, 좁은 화면에서는 상세가 아래에 배치됩니다. Escape 또는 닫기 버튼으로 돌아갑니다.
- 조합 상세의 시설 이름 또는 이미지를 누르면 건축 카탈로그가 열리고 해당 시설이 선택됩니다. 미발견 조합에서도 확인할 수 있습니다. 이동한 카드는 이리디센스 테두리와 **도감에서 찾은 시설** 배지로 강조됩니다.
- 미발견 조합에서 아직 설치하지 않은 시설은 **청록 실루엣**, 설치한 시설은 **흑백**으로 표시합니다. 조합을 발견하면 두 시설 모두 **원본 컬러**로 표시합니다. 상단 진행 막대는 검색·필터와 관계없이 전체 발견 비율을 보여 줍니다.
- 미발견 조합에도 보상이 있으면 수수료 오른쪽에 **선물·잠김 표시**가 보입니다. 마우스를 올리면 발견 후 받을 골드를 확인할 수 있으며, 발견 전에는 수령할 수 없습니다. 발견하면 같은 크기의 받기 버튼으로 바뀝니다.
- 발견했지만 아직 보상을 받지 않은 조합은 수수료 오른쪽에 **선물·받기 버튼**이 표시됩니다. 짙은 청록 바탕의 테두리에 금빛·민트·보랏빛 이리디센스 광택이 흐르며, 마우스를 올리면 테두리가 밝아지고 받을 골드를 확인할 수 있습니다.
- 클릭하면 골드가 지급되고 **움직임 없는 초록 체크·완료 배지**로 바뀝니다. 완료 배지는 버튼이 아니므로 다시 누를 수 없습니다. 발견 시점에는 자동 지급하지 않으며, 효과가 현재 적용되지 않는 조합도 보상을 받을 수 있습니다.
- 발견 기록과 수령 기록을 따로 저장하므로 게임을 다시 실행해도 받지 않은 보상을 수령할 수 있습니다.

## 한 번만 지급되는 기준

- 조합에 필요한 시설 두 종류가 실제로 설치되면 발견합니다. 설치 미리보기만으로 발견되거나 보상이 지급되지는 않습니다.
- 발견에는 시설 사이의 거리 조건이 없습니다. **최대 거리 (미터)**는 발견 후 지속적으로 받는 **추가 수익 (%)**에만 적용됩니다.
- 동일 조합은 저장된 수령 이력을 기준으로 한 번만 보상받습니다. 시설을 이동·철거·재설치하거나 저장 파일을 다시 불러와도 수령한 보상이 다시 지급되지 않습니다.
- 자동 지급 방식으로 기록된 기존 발견 이력은 수령 완료로 이전하며 소급 지급하지 않습니다. 새 방식에서는 아직 수령하지 않은 조합에 현재 표의 보상 금액을 적용합니다.
- Row Name은 발견 이력을 식별하는 ID입니다. 기존 조합의 표시 이름과 보상은 바꿔도 되지만, 같은 조합을 유지하려면 Row Name은 그대로 둡니다.

## 표에서 함께 조정하는 값

| 항목 | 의미 |
|---|---|
| 사용 | 끄면 해당 조합을 적용하지 않습니다. |
| 조합 이름 | 플레이어에게 보여 주는 제목입니다. 시설 ID와 별개입니다. |
| 수익을 받는 시설 ID | 추가 수익이 적용되는 부스 종류입니다. |
| 함께 놓을 시설 ID | 해당 부스를 돕는 시설 종류입니다. |
| 최대 거리 (미터) | 두 시설 중심 사이의 수평 거리입니다. 경계까지 포함합니다. |
| 추가 수익 (%) | 10이면 해당 부스의 일반 이용 수익에 +10%입니다. |
| 최초 발견 보상 (골드) | 해당 조합을 발견한 뒤 도감에서 한 번 수령하는 금액입니다. |
| 중복 방지 그룹 | 같은 부스의 같은 그룹에서는 가장 큰 수익 보너스 하나만 적용됩니다. 발견 보상과는 별개입니다. |

초기 조합은 휴식 `FoodComfort`, 조명 `Ambience`, 공연·포토존 `Attraction` 그룹을 사용하며 추가 수익은 6~12%, 거리는 12~18m입니다. 같은 상대 시설을 여러 개 설치해도 같은 행의 수익 보너스는 중첩되지 않습니다. 전체 수익 보너스에는 Project Settings의 시설당 추가 수익 상한이 적용됩니다.

## CSV 확장과 기존 편집값 보존

게임은 `data/unreal/facility_synergies_v0.csv` 파일이 아니라 **저장된 DT_FacilitySynergies** 에셋을 읽습니다. 평소 보상 조정은 DataTable에서 하면 됩니다.

기존 표에 최신 CSV의 새 조합만 추가하려면 먼저 표를 저장한 후 Editor 콘솔에서 `FF.AppendFacilitySynergyRows`를 실행합니다. 기존 행의 조합 이름·거리·수익·발견 보상과 별도로 만든 행을 모두 보존하고, 없는 Row Name만 추가합니다. 다시 실행해도 같은 조합을 중복 추가하지 않습니다. 표 자체가 없는 프로젝트의 최초 생성은 `FF.CreateFacilitySynergyTable`을 사용합니다.

CSV를 직접 Import/Reimport하면 기존 표 편집값을 덮을 수 있습니다. 기존 조합을 유지한 채 확장할 때는 위 추가 명령을 사용하세요. 시설 ID는 에셋 파일명에서 추측하지 말고 행 편집기의 ID 선택 목록을 사용합니다.
