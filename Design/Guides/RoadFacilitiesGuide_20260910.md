# 길 시설 6종 통합

기준 이미지 `Road.png`의 모래·아스팔트·목재·돌·헤링본·콘크리트를 각각 설치 가능한 길 시설로 구성한다. 한 타일의 제작 규격은 400 × 400 × 8 cm이며, 설치 가격은 각 100이다.

## 카탈로그와 데이터

시설 대분류 `Road`는 기존 열거형 값 뒤에 추가해 이전 시설 카테고리의 저장값을 유지한다. UI에는 길 카테고리로 표시하고, 시설 ID는 `Road_Surface_Sand`, `Road_Surface_Asphalt`, `Road_Surface_Wood`, `Road_Surface_Stone`, `Road_Surface_Herringbone`, `Road_Surface_Concrete`를 사용한다.

메시는 `/Game/Asset/FacilitiesAsset_HKH/Roads`, 시설 정의는 `/Game/FestaFiesta/Zone/Data/FacilityDefinitions/Road`에 위치한다. 가격·카테고리·메시·썸네일은 시설 정의 및 카탈로그 검사로 확인한다. 길은 서비스, 대기열, 관람객 목적지로 사용하지 않는다.

## 길 위 시설 설치

길은 일반 시설의 배치를 지원하는 바닥이다. 길이 점유 영역을 막지 않도록 배치 검증, 건설 가능 영역 표시, 등록, 저장 복원에서 같은 규칙을 사용한다. 일반 시설끼리의 충돌과 건설 구역 제한은 계속 적용한다.

시설 설치 높이는 길의 윗면을 반영한다. 메시 비동기 로딩 중에도 길 정의의 높이를 사용할 수 있어야 한다. 길의 시각 메시에는 표면 추적과 플레이어 충돌을 유지하고, 길 때문에 NPC 내비게이션 장애물을 추가하지 않는다.

길의 지원 높이와 충돌 예외는 길 시설에만 적용한다. 기존 조명이나 다른 시설의 서비스·수용량·비용·설치 검증을 바꾸는 근거로 사용하지 않는다.

각 길 PDA는 `Spec > Placement > 길 위 시설 설치 허용`(`bAllowFacilityPlacementOnTop`) 옵션을 제공하며 여섯 종류 모두 기본값은 켜짐이다. 옵션을 끈 길은 일반 시설의 본체·여유 공간·대기열과의 중복 설치를 막는다. 저장 복원과 건설 가능 영역 표시도 같은 옵션을 반영한다.

상부 시설이 있는 길은 그 시설을 먼저 옮긴 후 이동·철거·크기 변경할 수 있다. 이미 설치된 시설 밑에 길을 새로 삽입하는 배치는 시설을 파묻지 않도록 차단한다. 길을 먼저 설치하고 시설을 올리는 순서로 배치한다.

NPC 높이는 기존 지형 높이에 가까운 길의 정확한 바닥 영역과 윗면 높이를 더해 계산한다. 길 목록은 배치 리비전이 바뀌거나 저장 상태가 복원될 때 갱신하고, NPC별 조회는 해당 공간 구획만 검사한다. 길은 군중 회피 벽에서도 제외한다. 상부 시설 허용 옵션을 꺼도 NPC는 길을 통행할 수 있다.

## 확인과 재실행

제작·임포트 설명은 `SourceArt/Roads_20260910/UE_IMPORT_GUIDE.md`에서 확인한다. 자동화는 다음처럼 실행한다.

```powershell
& ./Tools/RoadFacilities/Run-RoadTests.ps1
```

`Tools/RoadFacilities/Run-RoadTests.ps1`은 `Saved/Roads_20260910`에 로그, 실행 기록, 테스트 결과를 남긴다. 프로세스 종료, 테스트별 성공, 각 필터의 실제 실행, 큐 완료를 모두 확인한다. 테스트 미실행이나 Python 오류를 성공으로 처리하지 않는다.

필수 확인 항목은 다음과 같다.

| 확인 항목 | 증거 |
| --- | --- |
| 여섯 길의 실제 메시·재질·LOD·충돌·크기 | Blender 및 Unreal 검사 보고서 |
| 길 카테고리 및 기존 카테고리 저장값 보존 | 이름 규칙·UI·카탈로그 자동화 |
| 설치 가격 100과 경제 데이터 연결 | 실제 카탈로그·경제 자동화 |
| 길 위 일반 시설 허용, 일반 시설 중복 차단 | `FF_ZoneSystem.Road` 자동화 |
| 길 높이 반영과 비동기 로딩 전 배치 | `FF_ZoneSystem.Road` 자동화 |
| 길 점유 예외의 저장·복원 일관성 | `FF_ZoneSystem.Road` 자동화 |
| 길별 상부 설치 허용/차단 옵션과 미리보기 | `FF_ZoneSystem.Road` 자동화 |
| 상부 시설을 지지하는 길 이동·철거 보호 | `FF_ZoneSystem.Road` 자동화 |
| 길은 NPC 목적지와 내비게이션 장애물이 아님 | NPC 브리지 및 길 자동화 |
| NPC 표면 높이·길 이동·삭제·저장 복원·회피 벽 | `FestaFiesta.Crowd.Road` 자동화 |
| 실제 게임 시점의 외형·이동·성능 | Unreal 캡처와 플레이 측정 기록 |

실행하지 않은 항목은 `NOT_RUN`으로 남긴다. 이 가이드에 기술된 의도와 실제 검수 성공 여부를 구분한다.
