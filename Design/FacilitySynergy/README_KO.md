# 시설 조합 설정 가이드

시설을 가까이 배치하면 지정한 부스의 이용 수수료가 늘어나는 기능입니다. 설치하거나 옮길 때 조합 상대와 거리 조건을 미리 볼 수 있습니다. **조합을 추가하거나 숫자를 바꾸는 데 코드를 수정할 필요가 없습니다.**

## 1. 먼저 알아둘 세 가지

- **수익을 받는 시설**은 보너스를 받는 쪽입니다. 예: Burger(버거 부스).
- **함께 놓을 시설**은 보너스 조건을 만들어 주는 쪽입니다. 예: Seating(좌석 시설). 좌석 자체에 새 매출이 생기는 것은 아닙니다.
- **최대 거리**는 두 시설의 중심 사이를 바닥과 나란하게 잰 거리입니다. `15`는 15미터입니다. 건물 가장자리 사이의 빈틈이나 손님이 걸어가는 길의 길이가 아닙니다.

수익 시설을 먼저 놓아도, 함께 놓을 시설을 먼저 놓아도 같은 결과입니다. 보너스는 조합을 완성하는 즉시 돈을 주는 보상이 아니라, 손님이 수익 시설을 이용했을 때 받는 수수료에 적용됩니다.

## 2. 조합표 열기

1. Unreal Editor에서 콘텐츠 브라우저를 엽니다.
2. `Content > FestaFiesta > Data > Economy` 폴더로 이동합니다.
3. `DT_FacilitySynergies`를 두 번 클릭합니다.
4. 왼쪽에서 조합 한 줄을 선택하고 아래의 행 편집기에서 값을 바꿉니다.
5. 저장한 뒤 실행 중인 플레이를 종료하고 다시 시작합니다. 표는 월드를 시작할 때 읽습니다.

**데이터테이블은 ‘한 줄에 조합 하나’를 적는 설정표**라고 생각하면 됩니다. 첫 열의 행 이름은 조합을 구분하는 고유 이름이고, ‘조합 이름’은 플레이어에게 보이는 이름입니다.

조합 이름은 `Burger + Seating`처럼 **실제 시설 이름을 연결해서** 적습니다. 시설 정의의 표시 이름을 나중에 바꾸었다면 조합표의 ‘조합 이름’도 함께 고쳐 주세요. 첫 열의 고유 행 이름은 변경할 필요가 없습니다.

기본 제공 조합은 다음과 같습니다. 초기 예시 값이므로 플레이 결과에 따라 조정하세요.

| 행 이름 | 조합 이름 | 수익을 받는 시설 | 함께 놓을 시설 | 최대 거리 | 추가 수익 | 중복 방지 그룹 |
|---|---|---|---|---|---|---|
| BurgerPicnic | Burger + Seating | Burger | Seating | 15m | 10% | FoodComfort |
| IceCreamShade | IceCream + Shade | IceCream | Shade | 15m | 10% | FoodComfort |

## 3. 각 항목에 무엇을 넣나요?

| 화면 항목 | 입력 방법 | 예시 / 주의점 |
|---|---|---|
| 사용 | 체크하면 적용, 해제하면 잠시 중단 | 행을 지우지 않고 효과만 끌 수 있습니다. |
| 조합 이름 | 실제 건축 목록의 시설 이름을 +로 연결 | `Burger + Seating` |
| 수익을 받는 시설 ID | 목록에서 보너스를 받을 시설 선택 | `Booth_FoodStall_Burger` |
| 함께 놓을 시설 ID | 목록에서 짝 시설 선택 | `Rest_Seating_Seating` |
| 최대 거리 (미터) | 0보다 크고 1000 이하 | `15` = 15미터. 정확히 15미터인 위치도 포함됩니다. |
| 추가 수익 (%) | 0보다 크고 1000 이하 | `10` = +10%. `0.1`을 넣으면 +0.1%입니다. |
| 중복 방지 그룹 | 겹치면 하나만 적용할 조합끼리 같은 이름 | `FoodComfort`. 비워 두면 다른 행과 더해집니다. |

시설 ID는 시설의 고유 이름입니다. 화면의 한글 이름, `PDA_`로 시작하는 에셋 이름, `Cost.`로 시작하는 비용 이름을 입력하는 칸이 아닙니다. 목록에서 선택하면 오타를 줄일 수 있습니다. 잘못된 값은 데이터 검증에서 이유를 알려줍니다.

## 4. 조합을 하나 더 추가하기

1. 기존 조합 행을 복제하거나 새 행을 추가합니다.
2. 행 이름을 겹치지 않게 정합니다. 예: `BurgerShade`.
3. 조합 이름을 실제 시설명을 연결한 `Burger + Shade`로 정합니다.
4. 수익을 받는 시설 ID에 `Booth_FoodStall_Burger`를 선택합니다.
5. 함께 놓을 시설 ID에 `Rest_Shade_Shade`를 선택합니다.
6. 최대 거리를 `15`, 추가 수익을 `15`로 정합니다.
7. 중복 방지 그룹을 기존 버거·좌석 조합과 같은 `FoodComfort`로 정합니다.
8. 저장하고 플레이를 다시 시작합니다.

이 예시에서는 버거 부스 주변에 좌석과 그늘이 모두 있어도 **같은 그룹의 더 큰 값인 +15%만** 적용됩니다. 두 효과를 합쳐 +25%로 만들고 싶다면 서로 다른 그룹 이름을 사용하세요.

한 행은 한 방향입니다. A와 B 모두 수익을 늘리려면 `A가 수익을 받는 행`과 `B가 수익을 받는 행`을 각각 작성합니다. 원래 이용 수수료가 0인 무료 시설은 퍼센트를 곱해도 0입니다.

## 5. 플레이 화면 읽기

1. 건축 모드에서 조합에 포함된 시설을 선택합니다.
2. 시설을 움직이면 옆의 안내 카드에 관련 조합과 상대 시설이 나타납니다.
3. 범위와 연결선을 보며 위치를 조절합니다. 안내 문구에서 거리 조건, 적용 여부와 수익 변화를 확인합니다.
4. 설치 가능 여부를 확인하고 확정합니다. 조합 조건 충족과 실제 설치 가능 여부는 별개입니다.
5. 기존 시설을 이동할 때도 새 위치의 결과를 미리 확인할 수 있습니다.

실선은 효과가 적용된 연결, 점선은 아직 적용되지 않은 연결입니다. 상대 시설의 번호는 안내 카드의 번호와 같습니다. 거리 원은 한꺼번에 겹쳐 보이지 않도록 **카드의 첫 번째 조합**만 표시합니다. 각 조합의 거리 조건은 카드에서 따로 확인할 수 있습니다.

카드의 `현재 → 배치 후` 보너스를 함께 보세요. 이미 다른 짝 시설이 같은 효과를 만들고 있다면 ‘기존 유지 · 추가 없음’으로 표시합니다. 시설을 옮겨 조합이 끊기면 감소하는 보너스도 미리 보여 줍니다.

기존 배치 미리보기의 **초록/빨강은 설치 가능 여부**입니다. 조합 안내는 별도의 선·표식·문구로 표시합니다. 설치할 수 없는 곳에서는 조합 보너스가 확정된 것처럼 안내하지 않습니다.

## 6. 배치한 시설에서 조합 확인하기

1. 이미 배치한 시설을 클릭해 ‘배치 시설’ 안내창을 엽니다.
2. **시설 정보 바로 오른쪽의 ‘조합’ 탭**을 누릅니다. 탭 순서는 시설 정보 → 조합 → 운영 → 강화입니다. 강화할 수 없는 시설은 강화 탭이 숨겨질 수 있습니다.
3. 조합 카드에서 함께 배치할 시설의 이름, 수익 효과, 거리 조건, 현재 적용 상태를 확인합니다.
4. 여러 조합이 있으면 아래로 스크롤해 모두 확인합니다. 등록된 조합이 없으면 빈 화면 대신 안내 문구가 나옵니다.

상대 시설의 이름은 **건축 목록에서 실제로 선택하는 시설 이름과 같습니다.** 예를 들어 건축 목록에 `Burger`라고 표시된 시설은 조합 안내에도 `Burger`로 표시합니다. 내부 데이터 ID나 개발용 에셋 이름을 보고 시설을 찾을 필요가 없습니다. 시설 이름을 바꾸려면 시설 정의의 Display Name을 수정하면 됩니다.

‘설정 효과’는 그 조합에 정한 보너스이고, ‘현재 적용’은 거리·중복 방지 그룹·전체 상한까지 반영한 결과입니다. 예를 들어 설정이 +10%여도 다른 조합이 우선 적용되면 추가 효과가 없을 수 있습니다. 좌석처럼 다른 시설을 도와주는 쪽을 선택했을 때에는 **어느 시설의 수익이 늘어나는지**를 함께 보여 줍니다.

### 클릭한 시설의 조합 상대를 건축 목록에서 찾기

1. 건축 모드에서 이미 배치한 `Burger`를 클릭합니다.
2. **B 키 또는 목록으로 돌아가기**를 눌러 건축 목록을 엽니다.
3. `Seating`이 목록 앞쪽에 나오며, 테두리와 **‘조합 시설’** 배지가 표시됩니다. `Seating`을 먼저 클릭했다면 반대로 `Burger`가 강조됩니다.
4. 강조된 카드를 선택하고 기존 시설 근처에 배치합니다. 실제 효과와 거리는 배치 미리보기에서 확인합니다.

새 시설을 기준으로 목록을 처음 열면 전체 분류의 첫 페이지를 보여 줍니다. 검색어와 ‘즐겨찾기만’ 조건도 이때 해제되어 다른 분류의 조합 상대를 찾을 수 있습니다. 그 뒤에는 분류·검색·즐겨찾기를 자유롭게 사용해도 강조 표시가 유지됩니다. 아래 안내의 `1/2종`은 현재 필터에서 보이는 조합 시설 종류가 전체 2종 중 1종이라는 뜻입니다.

**배지는 함께 배치할 수 있는 조합이라는 뜻입니다.** 아직 거리를 충족했거나 추가 수익이 확정되었다는 뜻은 아닙니다. 잔액 부족·건축 한도는 그대로 적용됩니다. 다른 시설을 클릭하면 기준이 바뀌고, 선택을 명시적으로 닫거나 기준 시설을 철거하거나 건축 모드를 종료하면 강조가 해제됩니다. 목록으로 돌아갈 때 정보창이 닫히는 경우에는 기준 시설을 기억합니다.

### 조합 상대 이름으로 바로 이동하기

시설 정보창의 **조합 탭 → ‘함께 놓을 시설’ 이름**을 누르면 그 시설의 건축 카드로 바로 이동합니다. 예를 들어 `Burger`의 조합에서 `Seating`을 누르면 휴게 분류의 `Seating` 카드가 보입니다. 검색어·즐겨찾기 조건 때문에 가려져 있던 경우에도 이름을 다시 찾을 필요가 없습니다. 시설이 있는 분류와 페이지를 열며, 자동으로 설치하지는 않습니다. 해당 카드를 선택하면 평소처럼 배치를 시작합니다. 목록을 불러오는 중이면 준비된 뒤 이동하며, 목록에서 나가면 대기 중인 이동은 취소됩니다.

### 배치 그리드가 유지되는 방식

한 번 확인된 지면과 같은 모양의 그리드는 그대로 유지합니다. 시간이 지났다는 이유로 선을 지웠다가 다시 그리지 않습니다. 시설을 설치·이동·철거하거나 지형·장애물이 실제로 바뀌면 필요한 부분을 다시 확인해 반영합니다. 화면 밖의 변경을 알아내기 위한 내부 검사는 남아 있지만 결과가 같으면 표시를 다시 만들지 않습니다.

### 건축 목록에서 필수 여부와 설치 현황 읽기

개수 제한이 있는 시설은 카드 오른쪽 아래에 **현재 설치 수 / 최대 설치 수**를 표시합니다. 예를 들어 최대 1개인 시설은 처음에 `0/1`, 설치하면 `1/1`, 철거하면 다시 `0/1`이 됩니다. 최대 3개 중 2개를 설치했다면 `2/3`입니다. 숫자의 오른쪽은 남은 개수가 아닌 전체 설치 한도입니다.

필수 시설은 별도의 **‘필수 설치’** 배지로 표시합니다. 축제에서 정한 최소 개수를 채우면 **‘필수 충족’**으로 바뀝니다. 설치를 완료해도 어떤 시설이 필수인지 계속 확인할 수 있습니다. 필수 시설이면서 조합 상대인 경우에는 두 표시가 함께 나타납니다.

카드에 마우스를 올리면 설치 한도와 필수 최소 개수, 배치할 수 없는 이유를 자세히 볼 수 있습니다. 한도에 도달했거나 잔액이 부족한 경우에는 숫자 표시를 유지하면서 추가 설치를 막습니다. 개수 제한이 없는 시설은 기존의 ‘배치 가능’ 등 상태 문구를 표시합니다.

필수 시설과 개수 제한은 서로 다른 설정입니다.

- **필수 시설·최소 개수:** `Content > FestaFiesta > Data > Festivals > DA_Festival_Busan`을 열고 `Required Setup Facilities`에서 시설과 `Minimum Count`를 정합니다. 다른 축제를 사용한다면 그 축제 설정 파일을 수정합니다.
- **최대 설치 개수:** 해당 시설의 정의 에셋을 열고 `Spec > Placement > Maximum Instances per World`를 정합니다. `1`이면 최대 1개, `0`이면 제한 없음입니다.

현재 기본 필수 시설은 `SunsetMainStage` 1개입니다. 필수 최소 개수는 최대 설치 개수를 넘지 않게 설정하세요. 재배치가 필요한 시설은 필수 조건 충족 개수에서 제외될 수 있습니다.

## 7. 보너스가 겹치는 규칙

- 같은 조합의 짝 시설을 여러 개 놓아도 해당 행은 한 번만 적용됩니다.
- 같은 ‘중복 방지 그룹’에서는 가장 큰 보너스 하나만 적용됩니다.
- 서로 다른 그룹의 보너스는 더합니다. 그룹이 비어 있으면 그 행은 독립적으로 더해집니다.
- 시설 하나의 전체 조합 보너스는 기본적으로 **최대 +50%**입니다.
- 상한은 `Project Settings > Game > FestaFiesta 시설 조합 > 시설당 추가 수익 상한 (%)`에서 바꿉니다. `0`이면 모든 조합의 금전 효과가 꺼집니다.
- 시설 강화와 조합은 함께 적용됩니다. 계산 예: 기존 수수료 × 강화 배수 × (1 + 조합 보너스 / 100).

예를 들어 기존 수수료가 100 Gold이고 강화가 1.5배, 조합이 +10%라면 165 Gold입니다. 실제 게임은 파티 인원까지 곱한 뒤 마지막에 한 번 반올림합니다. 소액 정산에서는 보너스가 있어도 표시되는 정수 금액이 같을 수 있습니다. 하루 전체 매출이 같은 비율로 늘어난다는 뜻도 아닙니다. 실제 방문·이용 인원에 따라 달라집니다.

## 8. 적용되지 않을 때 확인할 순서

| 증상 | 먼저 확인할 것 |
|---|---|
| 관련 조합이 보이지 않음 | ‘사용’ 체크, 양쪽 시설 ID, 저장 후 플레이 재시작 |
| 붙여 놓았는데 거리 초과 | 가장자리가 아니라 중심 간 거리인지 확인. 큰 시설은 거리를 더 넓게 잡아야 할 수 있습니다. |
| 상대가 있어도 추가 수익이 0 | 같은 그룹의 더 큰 조합, 이미 충족된 조합, 전체 상한을 확인 |
| 무료 시설의 수입이 안 늘어남 | 무료 시설 대신 수수료가 있는 부스를 ‘수익을 받는 시설’로 지정 |
| +10%인데 1인 표시액이 그대로 | 최종 정수 반올림 영향. 여러 명 이용 시 정산액과 함께 확인 |
| 표가 있지만 적용되지 않음 | 프로젝트 설정의 ‘시설 조합 데이터표’가 `DT_FacilitySynergies`인지 확인 |

내부 구역 경계는 조합 거리를 끊지 않습니다. 현재 규칙은 수평 거리이며 벽, 장애물, 도로 연결이나 실제 보행 경로는 별도 조합 조건으로 검사하지 않습니다.

설치가 완료된 짝 시설은 영업을 닫아도 배치 효과를 유지합니다. 아직 설치되지 않은 계획 시설, 철거된 시설, 재배치가 필요한 시설은 조합 상대에서 제외됩니다.

## 9. 디자이너가 화면 모양 바꾸기 — UMG / WBP

**게임 규칙은 `DT_FacilitySynergies`, 화면 모양은 `WBP_FF_BuildSynergy`에서 바꿉니다.** WBP는 버튼과 글자, 배경을 눈으로 배치하는 Unreal의 화면 설계 파일입니다.

1. 콘텐츠 브라우저에서 `Content > FestaFiesta > UI > Building`을 엽니다.
2. `WBP_FF_BuildSynergy`를 두 번 클릭합니다.
3. **Designer** 화면에서 바꿀 위젯을 선택합니다.
4. 오른쪽 Details에서 위치·크기·글꼴·색·여백을 바꿉니다.
5. **Compile → Save**를 누르고 플레이에서 확인합니다.

| 바꾸고 싶은 것 | 선택할 곳 | 바꿀 값 |
|---|---|---|
| 안내창 위치 | `Size_Synergy` | Canvas Slot의 Position / Anchors / Alignment |
| 안내창 너비 | `Size_Synergy` | Width Override |
| 배경·테두리·안쪽 여백 | `Border_Synergy` | Brush / Brush Color / Padding |
| 맨 위 제목 | `Text_SynergyHeading` | Text / Font / Color |
| 조합 이름 글꼴 | `Text_SynergyTitle_1`부터 `_3`까지 | Font / Color / Slot Padding |
| 조합 설명 글꼴 | `Text_SynergyDetail_1`부터 `_3`까지 | Font / Color / Slot Padding |
| 연결선과 원의 모양 | 상단 **Class Defaults**의 Style 항목 | 아래 설정표 참고 |

연결선은 시설의 실제 위치를 따라 그려집니다. Designer에서 선을 직접 끌어 옮기는 대신 다음 설정으로 모양을 바꿉니다.

| Class Defaults 속성 | 뜻 |
|---|---|
| 효과 적용 연결선 색 / 미적용 연결선 색 | 효과 적용 / 미적용 상태의 선과 표식 색 |
| 적용 연결선 두께 / 미적용 연결선 두께 | 각 상태의 연결선 굵기 |
| 거리 원 선 두께 / 거리 원 불투명도 | 거리 범위 원의 굵기 / 불투명도 |
| 시설 표시 크기 / 시설 표시 선 두께 / 시설 번호 글자 크기 | 상대 시설 표식 크기 / 테두리 굵기 / 번호 크기 |
| 상태별 제목 색 사용 | 켜면 상태에 따라 조합 제목 색을 바꿉니다. 끄면 Designer에서 정한 글자색을 유지합니다. |
| 효과 적용 제목 색 / 미적용 제목 색 | 위 옵션을 켰을 때 사용할 제목 색 |

**연결된 위젯의 이름과 종류는 유지하세요.** `Border_Synergy`는 Border, `Text_SynergyLegend`, `Text_SynergyFooter`, `Text_SynergyTitle_1~3`, `Text_SynergyDetail_1~3`은 Text Block입니다. 이 이름으로 게임 데이터가 들어옵니다. 이름을 그대로 두고 위치·부모 레이아웃·색·글꼴·장식을 수정할 수 있습니다.

조합 이름·상대 시설·거리·보너스 숫자는 플레이할 때 자동으로 바뀝니다. 이 문구의 **내용**을 바꾸려면 조합표를 수정하고, **모양**을 바꾸려면 WBP를 수정하세요. 동시에 표시하는 조합은 최대 3개이며, 변화가 큰 조합과 가까운 상대를 우선합니다. 나머지는 개수로 안내합니다.

처음에는 1280×720과 1920×1080에서 확인하세요. 오른쪽 위 HUD와 아래쪽 건축 도구를 가리지 않고 세 개의 조합이 모두 읽히는지 보는 것이 중요합니다. 기본 위젯은 배치 마우스 입력을 막지 않도록 설정되어 있습니다.

고급 연출이 필요하면 WBP Graph의 `BP_OnPreviewChanged` 이벤트와 `PreviewData`로 애니메이션 등을 연결할 수 있습니다. `BP_OnPreviewCleared`는 배치 취소·일시정지 등으로 안내가 사라질 때 호출됩니다. 수익 판정은 이 이벤트에서 다시 계산하지 않습니다.

배치한 시설의 ‘조합’ 탭은 별도의 WBP에서 편집합니다.

| 바꾸고 싶은 것 | 에셋 / 위젯 |
|---|---|
| 조합 탭 위치·버튼 모양 | `Content/FestaFiesta/UI/Facility/WBP_FF_FacilityInfoPanel`의 `Button_TabSynergy` |
| 조합 페이지 구성·정렬 | 같은 WBP의 `Panel_SynergySection` |
| 현재 전체 효과 요약 | 같은 WBP의 `Text_SynergySummary` |
| 조합 카드 목록 위치·정렬 | 같은 WBP의 `VerticalBox_SynergyEntries` |
| 카드 하나의 글꼴·색·배치 | `Content/FestaFiesta/UI/Facility/WBP_FF_FacilitySynergyEntry` |

조합 카드는 설정된 조합 수에 맞춰 자동으로 나타납니다. 카드 에셋 하나를 고치면 모든 카드에 같은 디자인이 적용됩니다. 탭과 카드에서도 데이터가 연결된 위젯의 이름과 종류를 유지하고 모양을 편집하세요.

카드 안의 `Text_Title`은 조합 이름, `Text_Partner`는 실제 시설 이름, `Text_Effect`는 수익 효과, `Text_Condition`은 거리 조건, `Text_Status`는 적용 상태입니다. 시설 이름이 긴 경우에도 읽을 수 있도록 자동 줄바꿈을 유지하는 것을 권장합니다. 카드 사이 여백은 카드 WBP의 `Border_EntrySpacing`, 카드 배경과 안쪽 여백은 `Border_Entry`에서 조절할 수 있습니다. 조합 페이지와 요약 문구의 세로 정렬은 Top(위쪽)을 유지하면 첫 줄이 잘리는 것을 방지할 수 있습니다.

### 건축 목록의 조합 강조 모양 바꾸기

1. `Content > FestaFiesta > UI > PrepHUD > Build`의 `WBP_FF_PrepBuildTile`을 엽니다.
2. `Border_SynergyHighlight`에서 강조 테두리의 색·두께를 수정합니다.
3. `Border_SynergyBadge`에서 배지 배경·여백을, `Text_SynergyBadge`에서 ‘조합 시설’ 문구·글꼴·색을 수정합니다.
4. Compile → Save 후 시설 클릭 → B → 건축 목록에서 확인합니다.

게임 코드는 강조의 표시·숨김만 바꾸므로 디자이너가 정한 색과 문구가 유지됩니다. 위젯 이름과 종류는 유지하세요. 고급 연출은 `BP_OnSynergyHighlightChanged` 이벤트로 연결할 수 있습니다. 이전 전체 화면 카탈로그를 사용하는 화면은 `Content/FestaFiesta/Zone/UI/Building/WBP_FF_BuildFacilityCard`의 같은 이름 위젯에서 편집합니다.

### 필수 배지와 설치 수의 모양 바꾸기

같은 `WBP_FF_PrepBuildTile`에서 부족 상태는 `Border_RequiredMissing` / `Text_RequiredMissing`, 충족 상태는 `Border_RequiredSatisfied` / `Text_RequiredSatisfied`를 편집합니다. 배경·글꼴·문구·여백은 WBP에 저장되며 게임은 두 상태의 표시 여부만 전환합니다. 조합 배지와 겹치지 않게 배치하세요.

`0/1` 같은 설치 수의 글꼴·정렬·색은 기존 `Text_State`에서 수정합니다. 숫자는 실제 설치 현황에서 자동으로 들어오므로 Designer의 예시 숫자를 바꾸어도 게임의 설치 수는 달라지지 않습니다. `BP_OnRequiredFacilityStatusChanged`로 추가 연출을 연결할 수 있습니다.

‘함께 놓을 시설’ 버튼은 `WBP_FF_FacilitySynergyEntry`의 `Button_OpenPartnerCatalog`에서 꾸밉니다. 안쪽 `Text_Partner` 이름을 유지하면 실제 시설명이 자동으로 들어옵니다. 버튼과 그 위의 부모 위젯은 자식 입력을 차단하지 않도록 설정하세요. 부모 레이아웃의 Visibility는 **Not Hit-Testable (Self Only)**를 사용할 수 있습니다.

## 10. 개발·유지보수 담당자 참고

- 행 형식: `/Script/FestaFiesta.FF_FacilitySynergyRow`.
- 런타임 표: `/Game/FestaFiesta/Data/Economy/DT_FacilitySynergies`.
- 재수입 원본: `data/unreal/facility_synergies_v0.csv`. 일반 편집은 에디터의 데이터테이블에서 합니다. CSV 재수입은 에디터에서 수정한 행을 바꾸므로 원본으로 관리하기로 정한 경우에만 사용합니다.
- 에셋이 없는 개발 환경에서는 프로젝트 빌드 후 에디터 콘솔의 `FF.CreateFacilitySynergyTable`로 생성합니다. 이미 있는 표는 덮어쓰지 않습니다.
- WBP가 없는 환경에서는 `FF.CreateBuildSynergyWidget`으로 기본 UMG 화면을 생성합니다. 기존 WBP의 Designer 트리와 Class Defaults는 덮어쓰지 않습니다. 화면 에셋은 `/Game/FestaFiesta/UI/Building/WBP_FF_BuildSynergy`입니다.
- 기존 시설 정보창에 조합 탭을 추가할 때에는 `FF.MigrateFacilitySynergyTab`을 사용합니다. 기존 탭과 디자인을 유지하면서 조합 탭 및 카드 WBP를 추가합니다. 이미 추가된 탭은 다시 만들지 않습니다.
- 기존 조합 카드의 상대 이름을 버튼으로 바꾸려면 `FF.MigrateFacilitySynergyPartnerLink`를 사용합니다. 원래 글자 스타일과 간격을 유지하며, 같은 명령을 다시 실행해도 기존 에셋을 다시 저장하지 않습니다.
- 배치 미리보기와 실제 수수료가 같은 조합 평가기를 사용합니다. 조합 값은 시설에 영구 저장하지 않고 현재 배치에서 계산하므로 이동·철거·불러오기 후에도 갱신됩니다.
- 전체 시설 검색을 매 프레임 수행하지 않습니다. 시설 변경을 감지한 뒤 필요한 시점에 검색 자료를 다시 만들고, 관련 시설 종류의 공간 인덱스로 조회합니다. 반복 수익 정산은 시설별 계산 결과를 재사용합니다.
- 배치 시설의 조합 목록도 선택 시설·시설 배치·시설 이름 목록이 바뀔 때 갱신합니다. 대기열 정보가 새로 들어올 때마다 조합을 다시 검색하지 않고, 화면의 카드도 재사용합니다.
- 건축 목록의 추천 상대는 활성·유효한 조합표에서 양방향으로 미리 정리합니다. 시설 선택 이벤트 때 종류별 목록을 조회하며, 매 프레임 월드 시설을 검색하거나 거리 계산을 하지 않습니다. 가상화된 카드가 다른 시설에 재사용되면 강조 상태도 교체합니다.
- 기존 카드 WBP에 강조 장식을 추가하는 명령은 `FF.AddBuildSynergyCardHighlights`입니다. 기존 카드 내용과 스타일을 보존하며, 이미 추가된 위젯은 다시 저장하지 않습니다.
- 조합 데이터 변경은 플레이 재시작 후 적용합니다. 실행 중 테이블 변경을 자동 적용하는 기능은 제공하지 않습니다.
- `/Game/FestaFiesta/Data`와 `/Game/FestaFiesta/UI`는 기존 패키징 설정의 항상 포함할 폴더이므로 기본 조합표와 WBP도 패키지에 포함됩니다.

검증 범위와 결과는 같은 폴더의 `VALIDATION.md`를 확인하세요.
