# 시설 조합 도감 · 사용과 화면 수정 가이드

시설을 어떤 짝과 함께 놓으면 좋은지 모아 보는 도감입니다. **조합 규칙은 기존 조합표에서, 화면 모양은 WBP에서 수정합니다.**

## 1. 도감 열기

1. 시설 배치 화면의 **이름·종류 검색 옆 ‘도감’** 버튼을 누릅니다.
2. 배치한 시설을 클릭한 뒤 **조합 → 시설 조합 도감**으로도 열 수 있습니다.
3. 어느 시설에서 열어도 **등록된 모든 조합**을 보여 줍니다. 미발견 조합도 회색 카드로 보이며 눌러서 조합 조건을 확인할 수 있습니다.
4. 이름 검색이나 **전체 / 발견 / 미발견**으로 찾고, 카드를 선택해 조합식과 거리·효과를 확인합니다.
5. 닫기 버튼이나 **Esc**로 돌아갑니다. 시설 배치 화면의 검색어와 페이지는 유지됩니다. 도감을 보는 동안에도 축제 시간은 흐릅니다.

## 2. 이렇게 읽으세요

- **시설 A + 시설 B → 수익 효과:** 두 시설을 정해진 거리 안에 배치하면 A의 이용 수수료에 보너스가 붙습니다. 새 시설을 합성하거나 재료를 소비하는 기능은 아닙니다.
- **발견 완료:** 조합에 필요한 두 시설의 설치를 모두 완료했다는 뜻입니다. 두 시설이 멀리 있어도 발견됩니다. 같은 종류끼리의 조합은 서로 다른 시설 2개가 필요합니다. 배치 미리보기나 카드 클릭은 포함하지 않습니다.
- **회색 카드:** 아직 발견하지 않은 조합입니다. 이름·짝 시설·효과를 미리 확인할 수 있으며, 발견하면 원래 색상으로 바뀝니다.
- **현재 조건 / 효과 적용:** 지금의 배치를 기준으로 표시합니다. 같은 그룹의 더 큰 효과나 전체 보너스 상한 때문에 조건을 채워도 실제 추가 효과가 없을 수 있습니다.
- 발견 기록은 같은 컴퓨터의 사용자 설정에 남습니다. 시설을 철거하거나 맵을 바꿔도 유지되며, 개별 축제 저장 슬롯과는 별개입니다.
- 거리는 **두 시설의 중심 사이 수평 거리**입니다. 보너스는 손님이 시설을 이용할 때 적용됩니다.

## 3. 조합을 추가하거나 수치를 바꾸기

1. 콘텐츠 브라우저에서 `FestaFiesta > Data > Economy > DT_FacilitySynergies`를 엽니다.
2. 한 줄이 조합 하나입니다. 기존 행을 복제한 뒤 **고유한 행 이름**을 정합니다.
3. `사용`, `조합 이름`, `수익을 받는 시설 ID`, `함께 놓을 시설 ID`, `최대 거리 (미터)`, `추가 수익 (%)`을 정합니다.
4. 효과가 겹칠 때 하나만 적용하려면 같은 `중복 방지 그룹`을 사용합니다.
5. 저장하고 플레이를 다시 시작하면 도감에 자동 반영됩니다. **도감용 목록을 따로 작성하지 않습니다.**

행 이름은 발견 기록의 기준입니다. 기존 조합의 표시 이름·수치는 바꿀 수 있지만, 행 이름을 바꾸면 새 조합으로 취급됩니다. 사용을 끈 행, 시설 ID가 비어 있거나 거리·수익 수치가 잘못된 행은 도감 개수에서 제외됩니다. 저장 전 에셋 검증(Validate)으로 시설 ID와 조합 이름도 확인하세요.

## 4. 디자이너가 화면 바꾸기

콘텐츠 브라우저에서 `FestaFiesta > UI > FacilityCodex`를 엽니다.

| 바꾸고 싶은 부분 | 열 파일 |
|---|---|
| 도감 전체 배치·검색·상세 설명 | `WBP_FF_FacilityCodexScreen` |
| 목록 카드의 크기·글꼴·색·이미지 배치 | `WBP_FF_FacilityCodexCard` |
| 시설 정보창 안의 도감 열기 버튼 | `WBP_FF_FacilityCodexLauncher` |
| 시설 배치 화면의 검색 옆 도감 버튼 | `WBP_FF_FacilityCodexCatalogLauncher` |

WBP는 화면을 눈으로 편집하는 설계 파일입니다. **Designer에서 수정 → Compile → Save**하면 됩니다. 연결된 위젯 이름과 종류는 유지하세요. 예: `TileView_Entries`는 카드 목록, `Search_Entries`는 검색창, `Button_Close`는 닫기 버튼입니다.

미발견 카드의 회색은 Card WBP의 **Class Defaults → Appearance → Undiscovered**에서 바꿉니다. 썸네일 흐림도 켜고 끌 수 있습니다. 발견한 카드는 Designer에서 지정한 원래 색상을 사용합니다.

카드 크기를 바꾸면 Screen의 `TileView_Entries`에서 **Entry Width / Entry Height / 항목 간격**도 맞춥니다. 시설 이름·이미지는 기존 시설 설정을 사용하고, 조합명·거리·효과는 조합표에서 자동으로 들어옵니다. 화면 색과 글꼴의 기본값은 프로젝트의 LightTeal·Pretendard를 따릅니다.

## 5. 마지막 확인

- 1280×720과 1920×1080에서 검색·카드·상세 설명·닫기 버튼이 읽히는지 확인합니다.
- 조합에 필요한 두 시설을 멀리 설치해도 발견되고, 거리 안에 함께 놓았을 때 현재 효과가 켜지는지 확인합니다.
- 조합을 늘린 뒤 검색·스크롤과 미발견 필터를 확인합니다.

개발자용 최초 생성 명령은 `FF.BuildFacilityCodexUMG`, 시설 정보창 연결은 `FF.MigrateFacilityCodexInspector`, 검색 옆 버튼 연결은 `FF.MigrateFacilityCodexCatalog`입니다. 이미 있는 도감 WBP는 재생성하지 않으며, 같은 명령을 다시 실행해도 디자이너가 편집한 화면을 보존합니다.
