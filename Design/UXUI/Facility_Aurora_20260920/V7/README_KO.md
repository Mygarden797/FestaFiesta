[원본·V6·V7 비교 페이지](index.html). 실제 프로젝트 장면 위에 UI를 얹은 정적 시안 12장이다. 게임 기능은 연결하지 않았다.

## 변경한 시각 규칙

| 역할 | 색과 표현 |
| --- | --- |
| 기본 정보 면 | 세이지 `#F3F8EE`, 짙은 녹색 글자 |
| 선택·실행 버튼 | 숲색 `#205039` 중심의 녹색 광택 |
| 이리디센스 테두리·헤더 | 에메랄드 `#58B994` → 민트 `#A6E7BB` → 연두 `#D7EFA7` |
| 프로그램 가능·오늘 매출 | 연속된 녹색 진주광, 짙은 글자로 수치 구분 |
| 강조 정보 카드 | 녹색 메쉬 그라디언트 |
| 월드 조작 안내 | 짙은 숲색 면과 연한 녹색 글자 |

보라·라일락·푸른 회색·샴페인 장식색을 제거했다. 카탈로그, 배치와 대기열, 시설 정보·조합·운영·강화, 프로그램, 매출 순위, 도감, 조명 편집과 축소 창에 공통 색상 규칙을 적용했다. 비교 갤러리도 같은 녹색 톤으로 맞췄다.

골드의 금색, 경고·철거 표시, 조명 색상환과 실제 선택 색 `#56DCE7`, 시설 썸네일 및 월드 장면의 색은 의미를 유지한다. 게임 장면 전체에 녹색 필터를 씌운 결과가 아니다. V7 재질은 `green-iridescence-v7.css`의 공통 토큰과 스타일로 정의했다.
