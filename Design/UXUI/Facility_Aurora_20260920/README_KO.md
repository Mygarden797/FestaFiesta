# 시설 UI 개선 시안 · Aurora LightTeal

2026-09-20 · V2 사용자 검토용 · **미승인 / 구현 승인 전**

사용자의 추가 요청에 따라 대기열 동선·정원·실시간 점유를 보강하고, 시설별 매출 순위를 재설계했습니다. 전체 6장에 같은 아이보리·세이지·딥그린과 진주빛 테두리, 입체감 있는 패널·버튼을 적용했습니다. V1 원본은 보존합니다.

첨부된 17개 게임 화면을 검토해 만든 이미지 중심 개선안입니다. 현재 단계는 디자인 검토이며 게임 코드, WBP, 게임 규칙에는 변경을 적용하지 않았습니다. 사용자가 시안을 통과시킨 뒤 실제 UMG 버튼과 기존 시스템을 연결합니다.

## 톤앤매너

기준은 현재 스크린샷과 `FF_UIPalette.h`의 LightTeal입니다. 다른 디자인 문서의 어두운 관제 화면으로 전환하지 않습니다.

| 역할 | 색상 |
| --- | --- |
| 기본 종이 면 | `#F7F8F6` |
| 보조 면 | `#EEF2EF` |
| 기본 Teal | `#527C6B` |
| 주요 버튼·선택 | `#315747` |
| 본문 | `#24332E` |
| 보조 글자 | `#6F7B75` |
| 구분선 | `#CCD5CF` |
| 주의 | `#E39A22` |
| 위험 | `#D74E43` |

- 이리디센스: 선택 카드와 포커스 테두리에 가는 민트·시안·라일락·연한 금빛 변화. 상태를 색만으로 전달하지 않습니다.
- 오로라 UI: 헤더와 특별한 상태 카드 뒤에 부드러운 빛 띠. 텍스트 뒤는 충분히 불투명하게 유지합니다.
- 메쉬 그라디언트: 넓은 밝은 면에 낮은 채도의 민트·아이보리·라일락 색 덩어리. 모든 카드에 반복하지 않습니다.
- Pretendard 계열 위계, 여유 있는 행간, 확실한 주요 행동. 경고·오류·철거에는 장식 효과를 적용하지 않습니다.
- 정적 이미지의 효과는 시각 방향입니다. 실제 머티리얼·애니메이션 구현과 성능 검증은 승인 후 진행합니다.

## 화면 의미와 구현 기준

화면의 수치·프로그램 예시는 디자인 검토용입니다. 실제 구현에서는 기존 데이터 모델과 시설 썸네일을 사용합니다. 생성 이미지의 모델 변형, 배경 장식, 부가 문구를 새 게임 에셋이나 새 기능으로 간주하지 않습니다.

1. 카탈로그는 시설 선택과 비교에 집중하고, 시설을 고르면 접힌 배치 도구로 전환합니다.
2. 배치 가능 여부와 조합 성립 여부를 분리합니다. 시설 영역은 실선, 안전 여유는 점선, 대기열 예약 공간은 별도 사선 영역·방향으로 구분합니다. 배치 중에는 정원과 동선만, 운영 중에는 실제 점유와 예상 시간을 표시합니다. 이용 중인 팀도 대기열 정원을 점유하고, 1인 이용 완료 예상은 본인 서비스 시간을 포함합니다.
3. 시설 정보와 프로그램 선택창은 서로 교체됩니다. 카드 선택만으로 비용을 사용하지 않고 금액이 표시된 확정 버튼에서 편성합니다.
4. 메인공연장 같은 집객 시설은 `직접 매출 없음 · 주변 부스 집객`로 설명합니다. 매출 0을 운영 실패처럼 표현하지 않습니다.
5. 조합 발견 기록과 현재 보너스 적용을 구분합니다. 조합은 시설을 소비하는 합성이 아니며, 조건 충족 시 지정된 시설의 이용 수수료에 자동 반영됩니다.
6. 강화는 수익뿐 아니라 시간·처리량·크기·비용·잔액을 비교합니다. Gold 부족, 공간 부족, 운영 중, 프로그램 보호, 최대 레벨을 구분합니다.
7. 철거 확인, 조명 설정, 지원 시설의 미니게임, 프로그램 영수증 등 기존 기능은 승인 후 구현 범위에서 유지합니다.
8. 매출 순위는 시설 종류별 합산이 아닌 설치 시설별 집계입니다. 공동 순위와 총액 0일 때 비중 `—`를 처리합니다.

V2의 구체적인 변경은 [V2_REVISION_SPEC_KO.md](V2_REVISION_SPEC_KO.md), 전체 버튼 연결과 상태는 [INTERACTION_SPEC_KO.md](INTERACTION_SPEC_KO.md)에 정리합니다. V2 생성 프롬프트와 원본 경로는 `IMAGEGEN_PROVENANCE_V2.json`, 최초 시안 기록은 `IMAGEGEN_PROVENANCE.json`을 참고합니다.

## 승인 후 완료 기준

- 승인된 레이아웃을 UMG/CommonUI로 구성하고, 글자와 버튼을 배경 PNG에 합쳐 굽지 않습니다.
- 기존 C++ 데이터·액션과 연결해 모든 표시 버튼의 동작, 비활성 사유, 탭·검색·필터·스크롤·단축키를 검증합니다.
- 1280×720, 1920×1080, 2560×1440에서 월드 입력·하단 HUD·우측 패널이 충돌하지 않는지 확인합니다.
- 배치/이동 취소, 비용 재검증, 프로그램 편성, 강화와 크기 변경, 철거 확인, 조합 적용, 매출 갱신을 실제 플레이로 확인합니다.
- 사용자 승인 범위에 맞는 실제 화면을 다시 캡처해 시안과 비교합니다.

이미지 제작에는 내장 `image_gen` 도구를 사용했습니다. 이번 산출물은 검토용 이미지와 명세이며 실제 기능 구현 완료를 의미하지 않습니다.
