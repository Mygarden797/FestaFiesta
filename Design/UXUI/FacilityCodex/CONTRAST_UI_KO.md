# 도감 대비와 강조 단계

2026-09-21. `SHOWCASE_UI_KO.md` 이후에 적용한 시각 조정입니다.

배경이 분류와 글자까지 흐리게 보이던 문제를 줄이고, 프로젝트의 녹색·세이지·종이색 팔레트로 조작 영역을 구분합니다. 기준은 `UFF_UIPalette::InGame`과 현재 시설 UI의 녹색 Action/Paper 표현입니다. 전역 팔레트나 다른 화면은 수정하지 않습니다.

- 바닥은 짙은 녹색 유리로 안정시키고, 패널과 카드의 글자가 배경 장면에 묻히지 않도록 비침을 줄입니다. 알파 혼합, 블러 한 번, 이리디센스 재질은 유지합니다.
- 분류·탭의 기본 상태는 밝은 세이지와 짙은 글자입니다. 현재 선택은 숲색 바탕·밝은 글자·민트 테두리로 구분합니다. 드롭다운 목록에도 같은 선택 규칙을 사용합니다.
- 검색창은 짙은 바탕으로 고정하고 호버·입력 포커스의 테두리를 선명하게 합니다.
- 일반 카드의 가장자리는 낮추고 선택 카드의 이리디센스 테두리는 두껍게 합니다. 시설 실루엣과 컬러 이미지는 기존 발견 상태를 그대로 따릅니다.
- 잠금 보상의 밝은 베이지 면을 낮은 채도의 녹색으로 바꿉니다. 선물과 잠금 글자는 유지하고, 수령 가능한 보상의 선물·금빛 테두리와 완료 체크를 구분합니다. 세 상태 모두 72×32를 유지합니다.
- 회전·닫기 같은 일반 행동의 비활성 상태는 선택 탭과 다른 회색 세이지 면을 사용합니다.

## 흰색을 섞은 후속 조정

사용자의 후속 요청에 따라 카드·상세 패널을 진주빛 종이색으로, 보조 정보 면을 옅은 아이보리·세이지로 바꿉니다. 제목 바와 선택 탭은 숲색을 유지하고 화면 바탕은 채도를 낮춘 회녹색입니다. 밝은 면 위의 본문은 짙은 잉크색이며 보상 금액은 읽기 쉬운 청동색입니다. 잠금 보상은 옅은 회색 면과 짙은 보조 글자로 표시합니다.

기존 투명도·모션·크기·발견 셰이더는 유지합니다. 흰 카드 위의 선택 테두리는 진주빛 바깥선과 짙은 녹색 안쪽선으로 구분합니다. 이 단계는 화면·카드 WBP 2개와 공용 Glass 머티리얼 1개만 저장합니다.

재적용: `Tools/FacilityCodex/apply_pearl_codex.py`. 백업과 반복 실행 검증은 `Saved/FacilityCodexPearl_20260921`에 보관합니다.

## 전체 배경을 밝힌 최종 방향

흰색을 화면 전체의 기준으로 확장합니다. 바깥 배경·제목 바·검색창·2D 및 3D 미리보기까지 프로젝트의 Paper/PaperSunken 계열로 통일합니다. 넓은 면의 녹색을 줄이고 제목·선택한 분류·진행도·보상 동작에 녹색을 집중합니다. 전체 배경의 불투명도는 96%로 높여 뒤쪽 장면 때문에 갈색·녹색으로 보이는 현상을 줄이고, 가장자리의 진주빛 이리디센스와 미세한 비침은 유지합니다.

최신 재적용 스크립트는 `Tools/FacilityCodex/apply_white_codex.py`입니다. 이 단계는 화면·카드 WBP 2개, Glass/Showcase 머티리얼 2개, Screen MI 1개만 저장하며, `Saved/FacilityCodexWhite_20260921`에 백업·검증·렌더를 보관합니다. 이전 Pearl/Contrast 적용 스크립트는 이전 단계 기록입니다.

흰 배경에서 검색 안내가 흐려지는 Slate 기본 힌트(알파 35%) 대신 입력을 가로막지 않는 안내 텍스트를 사용합니다. 검색 입력의 원래 공간을 채우는 Overlay에 배치하며, 입력 시 숨기고 지우면 다시 표시합니다. 보상 버튼 세 상태의 72×32 크기는 유지합니다.

## 발견 보상 수령 상태와 피드백

흰색 배경과 프로젝트의 숲색 선택 표시를 유지하면서 보상 상태를 색·아이콘·움직임으로 구분합니다. 카드와 상세의 보상 영역은 미발견/수령 가능/수령 완료 모두 72×32입니다.

- 수령 가능: 금빛 선물과 짙은 청동색 글자. 이리디센스 셰이더의 느린 광택 이동과 작은 가장자리 반짝임으로 클릭할 곳을 강조합니다. 호버는 테두리를 선명하게, 누름은 정적인 눌림 면으로 표현합니다.
- 수령 완료: 정적인 옅은 세이지 면과 짙은 체크 아이콘. 움직이는 광택을 없애 수령 가능한 선물과 구분합니다.
- 미발견: 기존 발견 썸네일 셰이더를 재사용한 실제 회색조 선물과 잠금 표시. 상세에는 보상 금액과 발견 후 수령 안내를 함께 표시합니다.
- 수령 가능 분류에 남은 보상 개수를 표시하고, 상세 안내도 상태에 맞게 갱신합니다.
- 실제 지급이 성공한 뒤에만 `＋N 골드 · 보상 수령 완료` 알림을 3초 표시합니다. 중복 요청과 실패는 새 알림을 만들지 않습니다. 짧은 등장 이동과 사라짐은 프로젝트의 모션 줄이기 설정을 따릅니다. 지갑 상한에 도달하면 이번에 실제 반영된 금액을 표시합니다.

재적용: 최신 Editor의 `/Engine/Maps/Entry`에서 `Tools/FacilityCodex/apply_reward_affordance.py`. 화면/카드 WBP 2개, 기존 보상 머티리얼 1개, 회색 선물 MI 1개를 저장합니다. `Saved/FacilityCodexRewardAffordance_20260921/migration-result.json`에 반복 실행 결과와 관련 없는 에셋 1,054개의 해시 보존을 기록합니다. UI 테스트의 저장 상태와 지갑은 별도 테스트 환경을 사용합니다.
