# 건축 UI 폰트와 전체화면 유리 도감

2026-09-21

도감을 열면 검색 결과나 발견 개수와 관계없이 화면 전체를 채웁니다. 32 UMG 단위의 내부 여백을 두고, 넓은 화면은 왼쪽 수집 목록과 오른쪽 상세 패널로 구성합니다. 논리 너비 1600 미만에서는 상세를 아래로 옮깁니다. 목록은 카드 너비에 따라 열 수를 조절하고 화면에 보이는 카드만 생성합니다.

## 폰트

`/Game/Asset/Font`에 들어 있는 원본 Font/FontFace 에셋을 사용합니다. 원본 폰트 에셋은 수정하지 않습니다.

| 용도 | 폰트 |
|---|---|
| 주요 제목 | NEXON Kart Gothic Korean Bold |
| 설명·도움말 | NEXON Lv2 Gothic |
| 버튼·시설 이름·일반 라벨 | NEXON Lv2 Gothic Medium |
| 건축 비용·보유 금액·수치 | NEXON Lv2 Gothic Bold |

건축 카탈로그, 배치 도구, 안내·비용·실패 피드백, 시설 정보·조명·프로그램·수익 화면, 도감 진입 버튼을 포함한 WBP 26개에 적용합니다. 도감 화면과 카드는 별도 디자인 변경에 포함됩니다. 아이콘 전용 문자는 기존 아이콘 폰트를 보존합니다. 저장된 위젯과 네이티브 대체 화면 모두 프로젝트 폰트를 사용하며, 실제 Font 에셋의 typeface 이름을 읽습니다.

## 유리 표현과 상호작용

짙은 바다색 유리, 민트색 윤곽, 금빛·진주빛 반사를 사용합니다. 카드 위의 시설은 밝은 민트 받침 위에 놓여 실루엣도 읽을 수 있습니다. 전체 배경의 블러는 한 번만 적용하고, 카드마다 블러를 추가하지 않습니다. 낮은 품질 설정에서도 반투명 대체 배경을 사용합니다.

UI 재질은 실제 알파 혼합으로 뒤의 화면을 비춥니다. 화면 배경은 54%, 헤더는 68%, 카드는 70%, 상세는 76%의 기본 불투명도를 사용합니다. 픽셀 단위 윤곽 계산으로 긴 헤더와 세로 패널에서도 모서리·테두리 두께를 유지합니다. 카드 배경은 정적이며 큰 표면과 선택 테두리만 천천히 색이 변합니다.

미발견·설치 여부에 따른 실루엣/흑백, 발견 후 컬러, 시설 클릭 시 카탈로그 강조, 직접 보상 수령을 유지합니다. 보상은 잠김·받기·완료 모두 72×32 단위이며 수령 여부 때문에 카드가 움직이지 않습니다. 검색·필터·상세 탭과 Escape 닫기도 유지합니다.

## 반영과 확인

최신 Editor 빌드의 실행하지 않는 `/Engine/Maps/Entry`에서 `Tools/FacilityCodex/apply_glass_codex.py`를 실행합니다. 새 재질을 만들고 `FF.ApplyBuildModeTypography`, `FF.ApplyFacilityCodexGlassTheme`를 순서대로 실행합니다. 기존 버전 표시가 있으면 Designer 편집을 덮어쓰지 않습니다.

- 원본 백업·재실행 해시 검사: `Saved/FacilityCodexGlass_20260921`
- 위젯별 폰트 감사: `Saved/Automation/BuildTypography/typography-audit.json`
- UI 렌더: `Saved/Automation/FacilityCodex`, `Saved/Automation/BuildableGrid`

도감 렌더 검증에는 투명도를 확인할 수 있는 고정 바다색·모래색 배경을 사용합니다. 이는 플레이어의 저장 상태를 읽지 않는 UI 검증용 배경입니다. 게임에서는 실제 뒤쪽 장면이 비칩니다.
