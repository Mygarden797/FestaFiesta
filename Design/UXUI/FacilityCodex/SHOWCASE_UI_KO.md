## 탐색과 정보

- 왼쪽 조합 카드는 기존 발견 상태와 수수료 효과, 선물 버튼을 함께 표시합니다.
- 시설 분류는 조합 효과를 받는 주 시설을 기준으로 필터링합니다. `수령 가능`은 발견했고 아직 보상을 받지 않은 조합만 표시합니다.
- 오른쪽에서 주 시설/함께할 시설을 전환합니다. 발견한 시설은 실제 시설 메시를 크게 표시하고 좌우 화살표로 회전하며 정면 버튼으로 돌아옵니다.
- 시설 이름 또는 조합 안의 시설을 누르면 해당 시설의 건축 카탈로그로 이동합니다. 기존 이리디센스 강조와 카테고리·페이지 이동을 유지합니다.
- 조합, 배치 조건, 현재 효과 탭 옆에 배치 거리와 최초 발견 보상을 표시합니다. 선물 아이콘은 목록과 상세 양쪽에서 기존 수동 수령 로직을 호출합니다.
- 미발견/수령 가능/수령 완료 상태의 보상 영역은 모두 72×32입니다. 미발견 상태에서도 보상 금액과 잠긴 선물로 보상의 존재를 알립니다.

## 미리보기와 표현

미발견 조합은 설치한 시설을 흑백, 아직 설치하지 않은 시설을 실루엣으로 표시합니다. 이때 컬러 3D 메시를 노출하지 않습니다. 발견하면 컬러 미리보기를 표시하고 메시가 없는 시설이나 로딩 중에는 기존 썸네일을 사용합니다.

3D 시설은 `UFF_FacilityCodexPreview`의 별도 `GamePreview` 월드에 일시적인 StaticMeshActor 한 개로 표시합니다. 게임 시설 액터를 생성하지 않으며 충돌·물리·내비게이션·액터 틱을 끕니다. 선택 변경과 닫기에서 비동기 로드 및 이전 액터를 정리합니다. 메시 중심을 보정해 회전하고 실제 크기·화면 비율에 맞게 카메라 거리를 계산합니다.

전체화면과 패널은 기존 알파 혼합 유리 재질을 유지하고 블러는 한 번만 적용합니다. 미리보기 테두리는 느린 이리디센스와 해안선·축제 불빛을 표현합니다. 3D 렌더 영역 자체는 UViewport의 불투명 바다색 배경이며, 주변 UI가 게임 화면을 투명하게 비춥니다.

논리 너비 1100 이상은 목록/미리보기의 좌우 구성이고, 그보다 좁으면 위아래로 배치합니다. 상세 내용은 세로 스크롤로 확인합니다. 목록은 남은 너비에 따라 카드 열 수를 조절하고 보이는 카드만 생성합니다.
