# 시설을 짓고 운영하는 방법

시설을 고르고 배치한 뒤, 대기열·매출·조합·프로그램·조명을 확인하는 방법입니다. 처음에는 1절의 순서대로 진행하고, 궁금한 버튼이나 화면이 있으면 해당 절을 찾아보세요. Gold는 게임에서 사용하는 돈입니다.

## 이번에 바뀐 점

- 시설 화면을 초록 계열 이리디센스(진주처럼 빛의 결이 달라지는 표현)로 맞췄습니다.
- 카드를 고른 뒤 비용을 확인하고 **선택해 배치**를 누르는 순서로 바꿨습니다.
- 배치 도움말은 왼쪽에, 자주 쓰는 버튼은 시설 이름 아래에 모았습니다. 대기열 정원도 함께 보입니다.
- 매출 순위에서 기간·금액·비중을 비교하고, 조합 도감에서 **발견**과 **적용 중**을 구분합니다.
- 시설 위 프로그램 표시와 오늘 매출에 초록 진주광을 적용했습니다.
- **조명 편집**을 시설 정보 옆 탭에 두었습니다. 색을 바꾸며 장면을 보고, 적용하거나 취소할 수 있습니다.

## 1. 처음이라면 이 순서로 진행하세요

1. **건축 카탈로그**에서 시설 카드를 선택합니다.
2. **설치 비용과 설치 후 남을 Gold**를 확인하고 **선택해 배치**를 누릅니다.
3. 게임 화면에서 위치와 방향을 정합니다. 왼쪽의 시설 크기·안전 여유·대기열 정보를 함께 확인합니다.
4. **배치 가능** 상태에서 **배치 확정**을 누릅니다. 설치가 성공하면 비용이 차감됩니다.
5. 설치한 시설을 클릭해 **시설 정보**를 엽니다.
6. 필요에 따라 **조합**, **운영**, **강화**, **조명 편집**으로 이동합니다. 시설마다 지원하는 기능은 다릅니다.
7. 운영을 시작한 뒤 **시설별 매출 순위**에서 실제 매출을 비교합니다.

카드를 선택하거나 배치 모습을 확인하는 것만으로는 시설을 구매하지 않습니다. 확정 버튼을 누르기 전에 비용과 조건을 살펴볼 수 있습니다.

## 2. 색과 표시를 읽는 방법

화면은 기존 시설 이미지와 축제 분위기에 맞춰 초록 계열의 진주광을 사용합니다. 옅은 민트와 잎색·짙은 초록을 겹쳐, 빛을 받은 진주처럼 보이는 **이리디센스 효과**를 표현했습니다.

| 표시 | 확인할 내용 |
| --- | --- |
| 초록 진주광 제목·선택 영역 | 지금 보고 있는 시설, 선택한 항목, 중요한 행동을 찾습니다. |
| **프로그램 가능** 배지 | 이 시설에서 편성할 수 있는 유료 프로그램이 있음을 뜻합니다. 구매 완료 표시는 아닙니다. |
| 배지 아래 **오늘 매출** | 해당 시설에 실제로 기록된 오늘의 매출입니다. 이 영역에도 초록 진주광이 적용됩니다. |
| Gold 숫자 | 설치비, 보유금, 구매 후 잔액처럼 돈과 관련된 숫자입니다. 숫자 옆 설명을 함께 읽습니다. |
| 흐린 버튼 또는 안내 문구 | 선택이 필요하거나, 현재 단계·자원·시설 상태 때문에 실행할 수 없는 기능입니다. |
| 경고·철거 표시 | 실행 전에 조건이나 회수 금액을 확인해야 하는 행동입니다. |

진주광은 중요한 정보를 쉽게 찾도록 돕는 표현입니다. 실제 보너스는 **적용 중**과 효과 수치로 확인하세요. 시설의 작은 미리 보기 이미지와 조명 색, Gold와 경고 표시는 각각의 색을 유지합니다.

| 시설 확인 / 건축 종료 | 설치된 시설을 살펴보거나 건축 화면을 종료합니다. |

Gold가 부족하거나 설치 한도에 도달하면 배치를 시작할 수 없습니다. 가격 정보의 **확인 중** 표시는 아직 비용을 불러오지 못했다는 뜻이며, 무료라는 뜻은 아닙니다.

## 4. 시설 배치·그리드·대기열: 현장을 보면서 조정하기

![배치 UI 검증 화면. 검은 영역은 배경을 제외한 부분이며, 금액·시설명은 검사용 예시입니다.](C:/Users/gksro/OneDrive/Desktop/Git/TeamProject/8th-Team13-Final-Project/Saved/Automation/BuildableGrid/BuildTools.png)

*배치 UI 검증 화면. 검은 영역은 배경을 제외한 부분이며, 금액·시설명은 검사용 예시입니다.*

화면 중앙에는 시설과 바닥이 보이고, 왼쪽에는 조작 방법과 시설 정보가 표시됩니다. 시설 이름 아래의 자주 쓰는 버튼으로 회전, 간격 맞춤, 그리드 표시, 배치 확정을 조작할 수 있습니다.

### 배치 전에 확인할 정보

| 정보 | 의미 |
| --- | --- |
| 시설 크기 | 시설 본체가 차지하는 가로·세로 길이입니다. |
| 안전 여유 | 시설 주변에 추가로 확보해야 하는 공간입니다. |
| 대기열 정보 | 해당 시설의 정원, 동시에 이용할 수 있는 인원, 1인 서비스 시간을 확인합니다. |
| 실선 / 점선 / 사선 안내 | 시설 본체, 안전 여유, 대기열 영역을 구별하는 화면 설명입니다. |
| 현재 맞춤 간격 | 움직일 때 위치를 맞추는 간격입니다. 작게 할수록 세밀하게 조정합니다. |
| 배치 가능 / 배치 불가 이유 | 현재 위치에 놓을 수 있는지를 알려 줍니다. 그리드가 보인다는 것만으로 설치 가능하다는 뜻은 아닙니다. |

배치 중의 대기열 정보는 **이 시설이 수용할 수 있는 인원**입니다. 지금 실제로 몇 명이 줄을 서 있는지는 설치 후 **운영** 탭에서 확인합니다. 그리드와 맞춤 간격은 위치를 정하는 도구이며, 시설의 정원은 바뀌지 않습니다.

### 자주 쓰는 조작

| 버튼·입력 | 역할 |
| --- | --- |
| 배치 확정 / 왼쪽 클릭 / Enter | 유효한 위치에 설치합니다. 이동 중에는 이동을 확정합니다. |
| Q / E | 시설을 45°씩 회전합니다. |
| Shift + Q / E | 누르는 동안 자유롭게 회전합니다. |
| 1 m / 25 cm / 1 cm | 기본 위치 맞춤 간격을 선택합니다. |
| Ctrl / Alt | 누르는 동안 각각 25 cm / 1 cm로 세밀하게 맞춥니다. |
| 그리드 / G | 그리드 표시를 켜거나 끕니다. |
| 세부 조정 | 각도 직접 입력과 구역 기준 X·Y 방향 미세 이동을 펼칩니다. |
| 시설 목록 / B / 오른쪽 클릭 | 시설 목록으로 돌아갑니다. 아직 확정하지 않은 새 시설은 설치되지 않습니다. |
| W / A / S / D | 카메라 위치를 움직여 현장을 확인합니다. |
| Esc | 배치 중에는 일시정지를 엽니다. |

각도를 직접 입력할 때는 0~360 사이의 숫자를 사용합니다. 세부 위치를 버튼으로 맞춘 뒤에는 **패널의 배치 확정**을 사용하면 마우스를 지면으로 옮기지 않고 확정할 수 있습니다.

연속 배치를 지원하는 항목은 화면에 **시설 연속 배치**와 별도 안내가 표시됩니다. 왼쪽 버튼을 누른 채 드래그하고, 놓으면 멈춥니다. 이때 여러 개가 실제로 설치되면 설치된 개수만큼 비용이 발생합니다. 일반 시설에 이 조작이 항상 적용되는 것은 아닙니다.

## 5. 시설 정보: 선택한 시설의 상태 확인하기

설치된 시설을 클릭하면 이름과 이미지, 분류가 있는 정보 창이 열립니다. 다른 시설을 선택하면 그 시설의 정보로 바뀝니다.

| 탭·버튼 | 확인하거나 실행하는 내용 |
| --- | --- |
| **시설 정보** | 크기, 안전 여유, 정원, 서비스 시간, 설치비·철거 회수액, 설치 한도, 매출, 유료 프로그램을 봅니다. |
| **조합** | 이 시설에 도움이 되는 짝 시설과 실제 적용 중인 효과를 봅니다. |
| **운영** | 운영 상태, 대기·이용 인원, 예상 시간과 처리 속도를 봅니다. |
| **강화** | 현재와 다음 단계의 차이, 강화비와 남을 Gold를 비교합니다. |
| **조명 편집** | 조명 색과 밝기를 현장에서 미리 보고 적용합니다. |
| ☆ | 해당 시설 종류를 즐겨찾기에 등록하거나 해제합니다. |
| 이동 | 기존 시설의 위치를 다시 정합니다. 이동 자체에는 설치비가 다시 붙지 않습니다. |
| 철거 | 철거 확인 화면을 엽니다. 시설 이름과 회수 금액을 확인한 뒤 최종 철거를 선택합니다. |
| 닫기 | 시설 정보 창을 닫습니다. |

모든 시설이 모든 기능을 지원하지는 않습니다. 조명이 없는 시설은 조명 편집이 보이지 않습니다. 강화가 없는 시설이나 강화할 수 없는 단계에서는 강화 버튼이 숨겨지거나 흐리게 표시됩니다. 이동·철거는 건축 변경이 허용되는 단계와 시설 상태에서만 가능합니다.

## 6. 시설 운영: 줄과 서비스 상태 읽기

**운영** 탭에서 실제 운영 상태를 확인합니다. 인원과 시간은 시설별로 달라지며, 게임 진행에 따라 갱신됩니다.

| 항목 | 읽는 방법 |
| --- | --- |
| 운영 상태 | 운영 중인지, 새 손님을 받을 수 있는지 확인합니다. |
| 대기·처리 중 일행 | 시설을 기다리거나 처리 중인 일행 수를 확인합니다. 사람 수와 팀 수는 서로 다른 단위입니다. |
| 대기·처리 중 인원 / 정원 | 현재 자리를 차지하는 인원과 시설 정원을 비교합니다. 서비스를 받고 있는 일행도 포함되며, 일행의 이용이 끝나면 자리가 비워집니다. |
| 남은 서비스 인원 | 현재 처리해야 할 서비스 인원입니다. |
| 1인 이용 완료 예상 | 새로 1명이 이용한다고 가정했을 때 끝날 때까지의 예상 시간입니다. 줄에서 기다리는 시간뿐 아니라 서비스 시간도 포함합니다. |
| 처리 속도 | 분당 처리할 수 있는 인원입니다. 실제 방문객 수나 매출을 보장하는 숫자는 아닙니다. |
| 시설별 매출 순위 → | 다른 수익 시설과 실제 매출을 비교합니다. |

**준비 중**은 아직 운영 정보를 받을 수 없는 상태이고, **사용 불가**는 해당 정보를 사용할 수 없는 상태입니다. 조명이나 바닥처럼 줄을 서서 이용하지 않는 시설은 **해당 없음**으로 나올 수 있습니다. 이를 대기 인원 0명과 혼동하지 마세요.

## 7. 시설별 매출 순위: 수익과 비중 비교하기

![매출 순위 UI 검증 화면. 테스트 시설명과 예시 매출을 사용했습니다.](C:/Users/gksro/OneDrive/Desktop/Git/TeamProject/8th-Team13-Final-Project/Saved/Automation/FacilityRevenue/RevenueRankingFixture720.png)

*매출 순위 UI 검증 화면. 테스트 시설명과 예시 매출을 사용했습니다.*

1. **오늘** 또는 **축제 누적**을 선택합니다.
2. 위쪽의 합계와 설치된 수익 시설 수를 확인합니다.
3. 목록에서 순위·시설 이름·매출·비중을 비교합니다.
4. 시설 한 줄을 선택합니다.
5. 아래의 **선택 시설 정보 보기**를 눌러 그 시설의 상세 정보를 엽니다.

매출이 같은 시설은 공동 순위입니다. 예를 들어 1위가 두 곳이면 다음 순위는 3위입니다. 같은 종류의 시설을 여러 개 지어도 설치된 시설별로 구분합니다. 철거한 시설은 현재 설치 시설 목록에서 제외됩니다.

### 0 Gold와 ‘—’는 다릅니다

| 표시 | 뜻 |
| --- | --- |
| 오늘 매출 **0 Gold** | 오늘 해당 시설에 기록된 매출이 아직 없습니다. |
| 합계 0 Gold와 **첫 매출을 기다리는 중** | 수익 시설은 있으나 선택한 기간의 기록된 매출이 모두 0입니다. |
| 매출 비중 **—** | 합계가 0이라 비중을 계산하지 않습니다. |
| 매출 비중 **0.0%** | 전체 매출은 있지만 이 시설의 비중이 0이거나 표시 단위보다 작습니다. 정확한 상황은 옆의 Gold 금액을 함께 확인합니다. |
| 설치된 수익 시설 없음 | 비교할 설치 시설 자체가 없습니다. |
| 조회 불가 / 준비 중 | 데이터를 아직 읽지 못했습니다. 0 Gold라는 뜻이 아닙니다. |

일반 시설 수수료는 손님의 이용이 끝나 실제 결제가 기록된 뒤 매출에 반영됩니다. 프로그램 수입은 해당 프로그램의 정산 규칙을 따릅니다. 직접 돈을 벌기보다 주변 시설의 방문을 돕는 시설도 있으므로, 모든 시설에 직접 매출이 있어야 하는 것은 아닙니다.

## 8. 시설 조합: 효과를 받을 배치 찾기

선택한 시설의 **조합** 탭은 이 시설과 관련된 조합을 보여 줍니다. 함께 둘 시설, 필요한 거리, 설정된 효과와 현재 적용되는 효과를 읽습니다.

1. 효과를 받고 싶은 시설의 조합을 확인합니다.
2. 짝 시설이 없다면 카탈로그에서 설치합니다.
3. 조합에 적힌 거리와 조건을 만족하도록 배치합니다.
4. **적용 중**과 **현재 적용 효과**를 다시 확인합니다.

조합의 `+8%` 같은 수치는 지정된 시설의 이용 수수료 등에 적용되는 보너스입니다. 축제 전체 매출이 그 비율만큼 무조건 오르거나 즉시 Gold를 받는다는 뜻은 아닙니다. 실제 값과 적용 대상은 각 조합 설명을 따릅니다.

## 9. 시설 조합 도감: 발견과 적용 구별하기

![조합 도감 UI 검증 화면. 예시 조합으로 카드와 상세 조건의 표시를 확인했습니다.](C:/Users/gksro/OneDrive/Desktop/Git/TeamProject/8th-Team13-Final-Project/Saved/Automation/FacilityCodex/FacilityCodex720.png)

*조합 도감 UI 검증 화면. 예시 조합으로 카드와 상세 조건의 표시를 확인했습니다.*

카탈로그의 도감 버튼이나 시설 조합 탭의 **시설 조합 도감 →**으로 엽니다. 카드 하나를 선택하면 상세 영역에 두 시설, 효과, 필요한 거리와 현재 조건이 나옵니다.

| 버튼·상태 | 의미 |
| --- | --- |
| 전체 | 모든 조합을 봅니다. |
| 발견 | 발견 기록이 있는 조합을 봅니다. |
| 미발견 | 아직 발견하지 못한 조합을 봅니다. |
| 적용 중 | 지금 실제 효과가 적용된 조합을 봅니다. |
| 검색 | 시설 또는 조합 이름으로 찾습니다. |
| 조건 체크 표시 | 필요한 시설 설치 여부와 현재 배치 조건을 확인합니다. |
| 닫기 / Esc | 도감을 닫습니다. |

**발견**은 조합을 알아냈다는 기록입니다. 필요한 두 시설의 설치가 완료되어 있으면 효과 거리 밖에서도 발견할 수 있습니다. 발견 뒤 시설을 옮기거나 철거해도 발견 기록은 남습니다.

**적용 중**은 지금 효과를 받고 있다는 상태입니다. 짝 시설이 현재 설치되어 있고 거리 등 조건을 만족해야 합니다. 같은 종류의 보너스 중 더 강한 효과가 우선하거나 적용 한도 때문에 효과가 줄어들 수도 있습니다.

그래서 **발견했지만 현재 효과는 0%**인 조합이 있을 수 있습니다. 상세 조건과 현재 적용 효과를 확인하세요. 같은 시설 두 개가 필요한 조합도 시설 한 개를 자기 자신과 조합할 수는 없습니다.

## 10. 유료 프로그램: 미리 보고 구매·편성하기

**프로그램 가능** 배지가 있는 시설을 선택한 뒤, 시설 정보의 **유료 프로그램 편성**을 누릅니다. 선택한 시설에 맞는 프로그램이 표시됩니다. 프로그램 편성이 가능한지는 Gold·인력·시간 조건에 따라 달라집니다.

1. 프로그램 카드를 선택합니다. 카드가 하나뿐이면 미리 선택되어 있을 수 있습니다.

**유료 프로그램은 오늘만 운영하며, 구매·편성 후 당일 취소와 환불은 불가합니다. 편성 후 해당 시설의 이동·강화·철거가 제한됩니다.** 구매 버튼을 누르기 전에 위치와 시간, 인력을 먼저 확인하세요.

프로그램 기능이 없는 시설에는 편성할 수 없다는 설명이 나옵니다. **프로그램 가능**과 **오늘 편성됨**은 서로 다른 상태입니다.

## 11. 시설 강화: 달라지는 값과 공간 확인하기

강화를 지원하는 시설을 선택하고 **강화** 탭을 엽니다. 현재 단계와 다음 단계의 이용 수수료, 1인 서비스 시간, 분당 처리 속도, 시설 크기를 비교합니다.

1. 강화 후 바뀌는 숫자와 시설 크기를 확인합니다.
2. 강화 비용과 구매 후 잔액을 확인합니다.
3. 조건을 만족하면 **Lv.… 강화 · … Gold** 버튼을 누릅니다.
4. 완료 안내와 바뀐 시설 상태를 확인합니다. 추가 공간이나 재배치 안내가 있다면 이를 처리합니다.

강화 실행이 성공하면 비용이 차감됩니다. 돈이 부족하거나 현재 시설 상태·단계에서 강화할 수 없으면 사유가 표시됩니다. 표시된 단계나 상태가 실행 전에 바뀐 경우에도 새 내용을 확인해야 합니다.

**강화에 쓴 비용은 나중에 시설을 철거해도 환불되지 않습니다.** 철거 시에는 별도로 표시되는 회수 금액을 확인합니다.

### 조명을 보면서 카메라 움직이기

1. 색이나 밝기를 바꿉니다.
2. **장면 확인 · 접어서 카메라 이동** 또는 **접기**를 눌러 편집 창을 작게 만듭니다. 상단을 드래그해 창 위치를 옮길 수도 있습니다.
3. 게임 화면에서 W/A/S/D로 이동하고, Q/E로 회전하고, 마우스 휠로 확대·축소하며 조명을 봅니다.
4. **펼치기**로 돌아와 세부 값을 다시 조정합니다.
5. 마음에 들면 **설정 적용**, 원래대로 돌리려면 **취소**를 선택합니다.

입력칸에 숫자나 색상 코드를 쓰고 있을 때는 글자 입력을 우선합니다. 카메라를 움직이려면 장면 확인 기능을 사용하거나 입력칸에서 벗어나세요. 창 위에서 휠을 사용할 때와 게임 화면 위에서 사용할 때의 동작도 구분됩니다.

### 적용과 취소의 차이

| 행동 | 결과 |
| --- | --- |
| 색·밝기 조정 | 게임 화면에 즉시 미리 보기가 나타납니다. 아직 최종 확정 전입니다. |
| 접기 / 장면 확인 / 펼치기 | 미리 보기와 선택 시설을 유지합니다. 이 동작만으로 적용하지 않습니다. |

| 적용하지 않고 다른 탭·시설로 이동하거나 정보 창 닫기 | 남아 있는 조명 미리 보기를 취소합니다. |

조명의 색과 밝기를 조절할 때는 Gold가 차감되지 않습니다.

## 15. V7 시안과 실제 게임의 관계

V7 시안은 초록 진주광과 화면 구성을 설명하는 디자인 참고 자료입니다. 실제 게임 화면에는 현재 플레이 중인 시설과 Gold·인원·매출·조합·프로그램 정보가 표시됩니다.

시안의 예시 숫자와 실제 플레이 기록은 다를 수 있습니다. 설치 가능한 시설과 프로그램은 축제 설정에 따라 달라지며, 창의 크기와 줄바꿈은 해상도와 UI 배율의 영향을 받습니다. 실제 실행 화면과 확인 결과는 아래 검증 기록에서 구분해 볼 수 있습니다.

2026년 9월 20일, Unreal Engine 5.7.4의 Windows 개발 빌드에서 확인했습니다.

**화면을 읽을 때:** 카탈로그 이미지는 실제 축제 맵에서 촬영했습니다. 검은 배경의 나머지 이미지는 게임에 저장된 UI를 따로 띄워 확인한 검증 화면입니다. 그 안의 시설 이름·인원·매출 예시는 실제 플레이 기록이 아닙니다.

**확인 범위:** 자동 검사와 실제 카탈로그 실행·시각 검토를 완료했습니다. 모든 시설을 사람이 직접 구매·이동·철거하는 전체 플레이나 최종 배포용 패키지 실행까지 확인한 기록은 아닙니다.

**남아 있는 기존 환경 경고:** 프로그램 자동 검사에서 손님이 없는 시험 상황의 정산 경고, 공통 HUD 아이콘 파일 누락 경고가 기록됐습니다. 실제 맵 실행에는 일부 구역의 이동 경로 경고도 있어, 전체 축제 플레이의 동선 확인은 별도입니다. 이번 UI 변경에서 맵이나 손님 이동 데이터를 수정하지 않았습니다.
