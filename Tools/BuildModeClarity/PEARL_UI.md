# 건축 모드 · 시설 조합 도감

2026-09-23 참고 이미지에 맞춘 UMG/WBP 변경.

## 게임에서 확인

- 준비 단계의 **배치** 탭: 반투명 하단 카탈로그. 좌우 드래그 또는 휠로 이어지는 목록을 탐색한다.
- 좌측 상단 뒤로가기: 현재 건축 작업의 종료/복귀 동작.
- 상단 그림 버튼으로 다중 선택, 격자, 위치 맞춤 간격, 시설 범위, 건축 설정, 시설 목록, 조작 안내를 연다. **F1~F7은 건축 중 아무 기능도 실행하지 않는다.**
- 다중 선택에서는 시설 클릭으로 선택을 전환하고 빈 지면에서 드래그해 영역을 선택한다. 선택 해제와 개별 시설 상세 확인을 제공한다. 화면의 종료 버튼으로 닫는다.
- 카탈로그의 **조합 도감**: 바다색 배경의 수집 카드 목록. 카드 클릭 시 별도 상세 화면, 상세의 뒤로가기는 목록으로 복귀한다.
- 도감은 시설별 최초 발견 보상과 수집 진행도 보상을 모두 기존 Gold로 지급한다. 수령 이력은 프로필에 저장된다.

## 가독성과 보상 표시 개선

- 시설 카드는 이름을 여러 줄로 표시할 수 있도록 폭과 높이를 늘리고, 이름 영역과 가격 영역을 분리했다.
- 우측 상단에 금화 아이콘·골드 라벨·잔액을 함께 표시한다. 상단 그림 버튼도 확대했다.（10/14 기준: 2026-09-29 작업에서 건축 상단 골드 배지를 숨겼다. 지금은 `FF_BuildToolsWidget.cpp`가 실행 중에 `Border_BuildToolbarGold`를 `Collapsed`로 둔다. 보유금 계산과 차감은 그대로이며, 자세한 내용은 [FACILITY_QUEUE_UI_GUIDE_KO.md](../../Design/Building/FACILITY_QUEUE_UI_GUIDE_KO.md) 4절에 있다.）
- 조작 안내는 차콜 패널 위에 마우스 좌클릭과 실제 키보드 키캡(Q/E, WASD, Ctrl, G, B, Esc)을 표시한다. 일반 배치와 직접 조정의 안내 문구는 실제 입력 동작에 맞춰 바뀐다.
- 조작 안내는 현재 시설 카탈로그의 화면 영역 위에 배치하며, 창이 작으면 안내 내부를 스크롤한다.
- Esc로 일시정지·옵션을 열면 상단 건축 도구와 조작 안내를 즉시 숨긴다. 복귀 시 같은 건축 상태와 안내의 열림 상태를 복원한다.
- 시설 정보의 조합 요약·레시피·상대 시설 링크·페이지 버튼은 본체와 같은 Pearl 색상, 하늘색 강조, 둥근 모서리를 사용한다.
- 조합 카드는 하단의 Gold 보상액·수령 상태 한 줄로 상태를 표시한다. 중복되는 잠김·완료 배지는 없애고, 수령 가능한 카드에만 받기 버튼을 표시한다.
- 상세 화면의 **발견 보상** 아래에는 금화 아이콘과 실제 골드 수치가 들어간 넓은 보상 버튼을 표시한다. 행 전체를 눌러 수령하며, 수령 후 같은 위치에 금액과 수령 완료 상태를 표시한다. 미발견 상태는 수령할 수 없다.
- 수집 진행도 보상은 진행선 위의 진한 금화 카드로 표시한다. 카드 밖 숫자는 필요한 발견 수량, 금화 우하단 숫자는 받는 골드 수치다. 수령 가능한 카드를 클릭하면 기존 골드로 지급한다.
- 별 문양 금화는 `Tools/ui/assets/StarEmbossedGoldCoin.png` 정본을 사용한다. 생성 도구와 프롬프트는 같은 폴더의 Markdown에 기록한다. 프로젝트의 공유 골드 텍스처를 같은 경로에서 교체하여 기존 연결을 유지한다.
- `Tools/ui/import_star_gold_coin.py`로 공통 골드 텍스처 두 개와 해당 이미지를 사용하는 WBP 여섯 개에 적용했다. RGBA 원본을 보존하고 UI 텍스처 크기는 256으로 제한한다. 원본 백업과 적용 기록은 `Saved/GoldCoinImport`에 있다.
- 시설 유료 프로그램 구매와 시설별 매출 순위는 같은 Pearl 색상과 둥근 표면을 사용한다. 준비 단계의 프로그램 편성 화면은 후속 요청에 따라 기존 디자인을 유지한다.

## 보상 설정

`Project Settings > Game > FestaFiesta 시설 조합 도감 > 수집 보상 단계`

기본 단계는 10 / 25 / 50 / 100개 발견, 각각 500 / 1,000 / 2,000 / 4,000 Gold다. 현재 조합 수보다 높은 단계는 표시하지 않는다. 이미 지급한 단계의 ID를 유지해야 수령 이력을 이어갈 수 있다.

## 편집 및 재생성

저장된 WBP는 `/Game/FestaFiesta/Building/FF_WBP_Building` 아래의 Catalog, Controls, Facility, FacilityCodex 폴더에 있다. Pearl UI 머티리얼은 `Controls/Pearl`에 있다. 일반적인 언리얼 재실행에는 별도 스크립트 실행이 필요 없다.

레이아웃 재생성은 빌드된 에디터의 빈 Entry 맵에서 `Tools/ui/apply_build_reference_ui.py`를 실행한다. 기존 WBP는 `Saved/BuildReferenceUI/backups`에 먼저 복사한다. 머티리얼은 `create_pearl_materials.py`와 `shaders/BuildPearl.ush`에서 재생성한다.

2026-09-24 조작 안내·시설 조합 보정만 적용하려면 `Tools/BuildModeClarity/apply_ui_fixes.py`를 실행한다. 건축 도구, 시설 정보, 조합 항목, 시설 정보의 도감 버튼 WBP 네 개를 백업한 뒤 적용하고, 나머지 UI 보존과 재실행 시 변경 없음 여부를 검사한다.

카탈로그 스크롤은 가상화된 가로 TileView의 오프셋을 움직인다. 썸네일은 비동기로 읽고, 정적인 UI 머티리얼을 공유한다. 시설 배치·가격·조합 조건은 기존 게임 시스템의 데이터를 사용한다.
