# FF Map Overview

기존 팀원 소스·설정·WBP·맵을 수정하지 않고 추가하는 건축 격자/지도 표시 기능입니다. UE 5.7 기준이며, 플러그인은 `EnabledByDefault`로 활성화됩니다. 에디터를 다시 실행하기 전에 C++ 빌드가 필요합니다.

## 사용

축제 준비/운영 HUD 우측 상단에 플레이어 중심 **100m × 100m** 원형 미니맵이 표시됩니다. 각 방향 50m까지의 주변을 원형으로 잘라 표시하고 이동을 따라갑니다. 캐릭터 조작 중에는 캐릭터 위치, 건축 관찰 모드에서는 사용자의 관찰 위치가 중심입니다. 참고 이미지의 얇은 이중 원, N/E/S/W 방위 표시, 육각 시설 아이콘을 적용했습니다.

- **상단바 격자:** 기존 버튼으로 격자 표시를 켜고 끕니다. 기존 `G` 단축키 상태도 유지합니다.
- **상단바 전체 격자:** `격자` 바로 오른쪽에서 등록된 건축영역 전체 표시를 켜고, 다시 누르면 주변 표시로 돌아갑니다. 격자가 꺼져 있으면 전체 표시를 켭니다.
- **지도 클릭:** 해당 위치로 관찰 카메라를 이동합니다.

격자 조작은 **건축 모드의 상단바에서만 표시**됩니다. 미니맵 아래 버튼과 `100m × 100m` 등의 숫자 문구를 모두 제거했으며 원형 지도·위치·방위 표시만 남습니다. 실제 지도 범위는 플레이어 중심 100m × 100m입니다. 일시정지·모달·연출·프론트엔드에서는 지도 입력을 차단합니다.

## 구조와 소유권

### 디자이너 편집

콘텐츠 브라우저의 **설정 → 플러그인 콘텐츠 표시**를 켠 뒤 `FF_MapOverview/UI`를 엽니다.

- `WBP_FF_MapOverview`: 화면 위치·지도 크기·나침반 글꼴/색을 UMG Designer에서 편집합니다. `MapPanel`의 우측 상단 앵커를 유지합니다.
- `WBP_FF_WholeGridButton`: 상단바의 `전체 격자` 버튼입니다. 기존 격자 버튼의 크기·브러시·글꼴·선택 스타일을 읽어 최초 생성하며, 이후 UMG Designer에서 편집합니다. `OnWholeGridStateChanged` 이벤트로 선택 애니메이션을 추가할 수 있습니다.
- `WBP_FF_MapMarker`: `Background` 육각형과 `Icon`의 배치/브러시를 편집합니다. Class Defaults의 종류별 색상·아이콘·`MarkerSize`를 변경합니다. 카메라 표시에도 이 WBP를 사용하며 별도 클래스를 지정할 수 있습니다.
- `MI_MapTerrain`: 투명도, 가장자리 부드러움, 지형 색/비네트를 편집합니다. `MapTexture`, `MapUVCenter`, `MapUVScale`은 실행 중 지역 지도 데이터로 갱신됩니다. 100m 범위를 맞추는 원형 마스크 반경은 0.45입니다.
- `MI_MapCompassRim`: 이중 원의 반경·간격·두께·색·투명도를 편집합니다.

미니맵의 위젯 이름 `MapSurface`, `TerrainImage`, `MarkerLayer`, `MapPanel`은 데이터 연결 계약입니다. 툴바 버튼 이름은 `WholeGridButton`, `Label`이며 `IconBounds` 안의 벡터 격자도 UMG에서 편집합니다. 이미지 아이콘으로 바꾸면 선택적인 `Icon` UImage 바인딩을 사용할 수 있습니다. 마커 이름은 `Background`, `Icon`입니다. 색상·크기·글꼴·브러시는 코드가 다시 생성하거나 덮어쓰지 않습니다.

런타임의 직접 위젯 트리 생성, 고정 미니맵 팔레트, Slate 원형 테두리/나침반/시설 아이콘은 제거했습니다. C++은 지도 데이터 투영과 입력을 담당하고 실제 디자인은 저장된 WBP·머티리얼 에셋에 있습니다. 에디터 전용 `FF.MapOverview.EnsureDesignerAssets` 명령은 **없는 에셋만 최초 생성**하며, 저장된 디자이너 에셋은 수정하지 않습니다. WBP가 없으면 코드 디자인을 대신 띄우지 않고 진단 로그를 남깁니다.

`FF_MapOverview`는 `FF_ZoneSystem`의 공개 건축 마스크와 지면 캐시를 소비합니다. 건설 명령·점유·저장·시설 정의를 수정하거나 설치 규칙을 복제하지 않습니다.

게임 연결은 새 `Source/FestaFiesta/Public/MapOverview/FF_MapOverviewBridge.h`와 새 `UFF_MapOverviewGameBridgeSubsystem` 어댑터에 격리됩니다. 플러그인은 `IModularFeatures` 계약으로 연결하며 게임 모듈 심볼에 의존하지 않습니다. 지도는 별도 로컬 플레이어 레이어에 표시됩니다. 전체 격자 WBP는 실제 상단바의 격자 오른쪽에 실행 중 삽입하고 종료 시 제거합니다. 기존 버튼 인스턴스·콜백·슬롯 설정을 보존하고 상단바 폭을 확장해 원래 입력 차단 영역에도 포함되도록 합니다. 원본 팀원 소스·WBP를 저장하거나 수정하지 않습니다.

기존 격자 컴포넌트는 새 표시 기능이 유효한 건축 세션 동안 렌더 가시성만 임시로 끕니다. 원래 가시성은 종료 시 복원합니다. 기존 세션 관리자의 계산/입력 수명은 유지되므로 아래 예산은 **새 격자 표시기 자체의 예산**입니다. 기존 표시기의 계산까지 없애는 변경은 팀원 소스를 수정하지 않는 범위에 포함하지 않았습니다.

## 성능

- 화면상 약 11픽셀 간격을 기준으로 격자 간격을 두 배씩 늘립니다. 9~18픽셀 유지 구간으로 작은 줌 변화에 따른 반복 재생성을 줄입니다. 저장/실제 위치 정렬 간격은 변경하지 않습니다.
- 새 표시기의 합산 보유 칸 **16,384개**, 선/테두리 합산 **32,768개**, 업데이트 지면 추적 배분 **최대 512개**, 권한 마스크 재생성 **최대 1회**로 제한합니다.
- 여러 지역은 예산을 나눠 순환 갱신합니다. 미확인/급경사/막힌 칸은 보이지 않으며 큰 범위는 점진적으로 표시됩니다.
- 전체 범위의 표시 칸이 커지면 포함한 원본 칸이 모두 비어 있을 때만 표시합니다. 정확한 설치 가능 여부는 선택 시설 전체의 기존 권한 검사로 결정합니다.
- 지면 표본이 대기 중이면 약 0.08초 간격, 안정된 지면 검사는 0.5초 간격, 외부 장애물 재확인은 2초 간격입니다. 변경된 권한 리비전은 다음 갱신에 반영합니다.
- 선택 시설 주변에는 별도 세부 격자를 배정합니다. 일반선/주요선/경계는 기존 **청록색 계열**, 두께 1.2/1.8/2.4픽셀, 불투명도 58/80/92%이며 어두운 테두리 32%를 적용합니다. 전체 표시에는 가장자리 흐림을 적용하지 않습니다.
- 미니맵 지형은 주변 200m를 512×512 정사영 SceneCapture로 캐시하고 그 안에서 플레이어 주변 100m를 잘라 표시합니다. 매 프레임/컴포넌트 이동 자동 촬영은 꺼져 있으며, 플레이어의 25m 단위 촬영 구역이 바뀔 때만 최대 0.5초에 한 번 촬영합니다. 정지 상태의 시설 변경 촬영은 최대 5초에 한 번입니다. 최초 스트리밍 안정화 촬영도 1회 수행합니다. 시설 데이터는 권한 변경 때만 읽고, 위치 투영과 배경 자르기는 약 10Hz로 갱신합니다.

`UFFMapOverviewSubsystem`의 `GetGridCellCount`, `GetGridLineCount`, `GetGridTraceBudget`, `GetGridSpacingCm`, `GetGridLastUpdateMs`로 표시기 상태를 확인할 수 있습니다. 추적 값은 실제 충돌 검사 횟수가 아니라 호출에 배정한 상한입니다.

## 검증

새 자동화 테스트 접두사는 `FF_MapOverview`입니다. 카메라 화면 맞춤/경계, 줌 간격·좌표 정렬·예산·설치 데이터 불변, 원형 지도 투영·클리핑·WBP 입력·720p/1080p 렌더·디자이너 편집 보존을 검사합니다.

`Tools/verify_runtime.py`는 별도 `UserDir`의 disposable editor에서 실제 `Test_Main` 축제 흐름을 실행해 미니맵 하단 위젯 부재, 상단바 삽입 순서·버튼 동작·건축 종료 후 제거, 100m 지도 추적, 카메라 전환, 격자 토글과 줌을 검사합니다. 시설 설치와 에셋 저장은 수행하지 않습니다. 결과는 프로젝트 `Saved/MapOverview/`에 기록합니다. 물리 마우스/키보드 입력 검증과 최종 패키지 GPU 성능 측정은 별도로 수행해야 합니다.
