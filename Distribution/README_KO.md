# FestaFiesta Windows 배포본

이 폴더는 Windows 64비트용 Shipping 빌드입니다. **ZIP 전체를 한 폴더에 압축 해제하고, 맨 위의 `FestaFiesta.exe` 하나를 더블클릭하세요.** 게임을 시작할 때 별도 명령어 입력이나 그래픽 모드 선택은 필요하지 않습니다.

`FestaFiesta.exe`는 게임의 입구이며, `FestaFiesta`와 `Engine` 폴더에는 실제 게임 데이터와 실행에 필요한 장비가 들어 있습니다. 실행 파일만 따로 옮기면 게임이 작동하지 않습니다. `FestaFiesta`, `Engine`, `Licenses`와 동봉 문서를 같은 위치에 유지하세요. 내부 실행 파일·DLL·콘텐츠 파일도 필요한 구성 요소입니다.

## 실행 환경

- 64비트 Windows 10 또는 Windows 11
- DirectX 12 및 Shader Model 6 지원 그래픽 환경 권장
- 최초 실행 전 `Engine/Extras/Redist/en-us/vc_redist.x64.exe` 설치 필요

## 그래픽 모드는 시작할 때 선택됩니다

게임은 기본 DirectX 12 / Shader Model 6 지원 여부를 확인하고, 이 경로가 지원되지 않으면 지원되는 환경에서 DirectX 11 / Shader Model 5를 선택합니다. 그래픽 장치를 만든 뒤 발생한 드라이버 오류나 플레이 중 비정상 종료까지 자동으로 복구하는 기능은 아닙니다.

두 셰이더 형식이 같은 배포본에 포함되어 있습니다. 셰이더는 GPU가 화면을 그리는 방법을 적은 프로그램이며, SM5/SM6는 GPU가 이해할 수 있는 기능 규격입니다. SM6 파일이 포함되어 있어도 GPU와 드라이버가 해당 기능을 지원해야 실행할 수 있습니다. DX11 모드에서는 SM6 전용 그래픽 기능을 사용할 수 없으며, 두 모드의 성능은 PC마다 다를 수 있습니다.

## 담당자용 고급 그래픽 검사

일반 사용자는 맨 위 `FestaFiesta.exe`를 더블클릭하면 됩니다. 두 그래픽 경로를 따로 검사하는 담당자만 게임을 종료하고, 압축을 해제한 맨 위 폴더에서 PowerShell을 연 뒤 아래 중 하나를 실행하세요. 한 모드를 종료한 뒤 다음 모드를 검사합니다.

```powershell
.\FestaFiesta.exe -dx11 -sm5
.\FestaFiesta.exe -dx12 -sm6
```

이 옵션은 특정 경로를 강제합니다. 강제로 지정한 경로가 지원되지 않을 때는 일반 실행의 자동 선택과 결과가 다를 수 있습니다.

SM5 실행이 가능하다는 사실만으로 모든 구형 GPU의 성능과 Windows/드라이버 조합을 보장하지는 않습니다. 실제 최소 사양은 검증된 테스트 PC 목록을 기준으로 배포처에서 확정해야 합니다.

## 무결성 확인

배포처에서 함께 제공하는 `PACKAGE-SHA256SUMS.txt` 또는 ZIP의 `ARCHIVE-SHA256.txt`와 다운로드한 파일의 SHA-256을 비교하세요. 빌드 버전과 소스 커밋은 `build-manifest.json`에 기록되어 있습니다.

`QUALITY-OVERRIDE.txt`가 있으면 일부 검증을 생략한 내부 확인용 빌드입니다. 공개 배포 승인본으로 취급하지 마세요.

## 배포 전 담당자가 확인할 사항

자동 검사에서는 패키지 구조, 필수 에셋과 SM5/SM6 셰이더 라이브러리 포함 여부를 확인합니다. `-GraphicsSmokeTest`까지 수행한 경우 DX11/SM5와 DX12/SM6의 그래픽 초기화를 확인합니다. 이 검사는 맵을 플레이하기 전에 종료하므로, 다음 수동 확인을 대신하지 않습니다.

1. 맨 위 `FestaFiesta.exe`를 더블클릭하고 첫 화면, 새 게임, 메인 맵 전환을 확인합니다.
2. 건설·시설, NPC, 시간 진행, 미니게임, 설정, 저장·불러오기를 실제로 조작합니다.
3. 검은 재질, 깜빡임, 빠진 그림자, 누락된 UI, 멈춤, 비정상 종료 여부를 기록합니다.
4. 종료 후 고급 검사 문단의 두 PowerShell 명령을 한 번에 하나씩 사용하여 DX11/SM5와 DX12/SM6에서 같은 순서를 반복합니다.
5. 개발 도구가 설치되지 않은 별도 PC에서 필수 구성 요소 설치와 실행을 확인합니다. GPU, 드라이버, 해상도, 그래픽 옵션, 측정 성능을 함께 기록합니다.

## 문제 보고

문제가 재현되면 다음 정보를 함께 전달하세요.

- `build-manifest.json`
- Windows 버전과 GPU/드라이버 버전
- 일반 더블클릭 실행인지, 고급 검사에서 옵션을 지정했는지
- 재현 순서
- `%LOCALAPPDATA%/FestaFiesta/Saved/Logs` 아래의 최신 로그(존재하는 경우)

Shipping 빌드는 일반 로그가 생성되지 않을 수 있습니다. 로그가 없으면 오류 화면과 발생 시각, 재현 순서를 우선 전달하세요.

외부 에셋과 라이선스 고지는 `Licenses/THIRD_PARTY_NOTICES.md`에서 확인할 수 있습니다.
