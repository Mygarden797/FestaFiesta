건축 UI 디자이너 편집 안내

승인된 Pearl 디자인을 WBP Designer와 로컬 HTML에서 편집하고, 같은 적용 스크립트로 다시 반영하는 방법입니다.

기준 화면 1920 × 1080건축 UI 범위2026.10.08

디자인 기준: 승인 v1 카탈로그 시안 · v1 치수 명세 · 색상 토큰. 시설·조명 편집은 최근 대화의 사용자 조명 이미지와 아래 최신 규격을 함께 따릅니다. 오른쪽 위 보유 골드 표시는 추가하지 않습니다.

적용 순서

  1. 변경한 네이티브 모듈을 먼저 빌드한 에디터를 사용하고, PIE를 종료합니다.
  2. 아래 패치 모듈의 크기·색·배치 값을 수정합니다. WBP에서 직접 수정한 값도 재적용 시 모듈 값으로 돌아오므로, 유지할 변경은 모듈에 함께 기록합니다.
  3. Unreal의 Tools → Execute Python Script에서 apply_reference_design.py를 실행합니다. 기존 노드를 재사용하도록 작성되어 같은 설정으로 다시 실행할 수 있습니다.
  4. Saved/BuildingReference20261008/latest-result.json에서 적용 결과를 확인합니다. 실행별 백업은 Saved/BuildingReference20261008/apply-*/Backup/, 보고서는 해당 실행 폴더의 report.json에 있습니다.
중앙 실행기는 모듈의 PACKAGES에 지정된 건축 WBP만 저장하고, 마지막 Blueprint 컴파일 뒤 apply_defaults(context)로 클래스 기본값을 반영합니다. 기존 HTML은 게임 폰트와 함께 다시 포함하며, 시설 썸네일 데이터는 그대로 사용합니다.

핵심 크기와 Designer 위치

상단의 즐겨찾기만·시설 검색·매출 순위·조합 도감은 NEXON Lv2 Gothic Regular 16pt를 공통으로 사용합니다. 검색 힌트와 즐겨찾기 개수도 같은 기준입니다.

시설 가격의 골드 아이콘은 하단 HUD와 같은 Tools/ui/assets/StarEmbossedGoldCoin.png 원본을 사용합니다. 웹에는 저장 시 PNG를 포함하고, UMG 카드는 기존 HUD 텍스처를 참조합니다. 원본과 하단 HUD 에셋은 수정하지 않습니다.

크기는 논리 디자인 단위입니다. UMG의 Font Size는 포인트이므로 CSS 픽셀과 숫자를 그대로 혼용하지 않습니다. DPI 배율과 실제 글꼴 메트릭은 별도로 고려합니다.

스타일을 수정할 파일

catalog_reference_patch.py

BUTTON_WIDTH, BUTTON_HEIGHT, SURFACE, INK, DANGER, REQUIRED_SURFACE. 두 버튼과 기존 필수 배지의 모양·폰트 및 카드 클래스 기본색을 편집합니다.

facility_reference_patch.py

apply()의 size(...), padding, font(...) 값. INFO·LIGHT 패키지만 대상으로 휠, 색상 견본, 프리셋, 하단 버튼을 구성합니다.

discovery_patch.py

FIRST_USE_BADGE_SIZE 20, REWARD_BADGE_SIZE 18. 빨간 ! 안내와 금색 G 보상 표시는 버튼 콘텐츠 바깥의 독립 오버레이입니다.

back_button_patch.py

기존 뒤로가기 버튼을 56 × 56 화살표로 표현합니다. 클릭 동작은 유지합니다.

WebUI/catalog-ribbon.html

실제 게임에 포함되는 시설 카드의 CSS와 DOM 표시입니다. 색상은 :root, 치수는 .card·.thumb·.name·.price에서 편집합니다. JS 연결 계약은 유지합니다.

표현과 게임 동작의 경계

필수 시설은 미충족일 때 빨간 ! 필수 현재/최소 배지와 연분홍 카드·2px 테두리, 충족 시 ✓ 필수 현재/최소로 표시합니다. 설치 수와 최소 수는 기존 시설 데이터에서 가져오며 디자이너용 예시 값으로 바꾸지 않습니다.

처음 사용 안내와 받을 보상은 별도 상태입니다. 빨간 !의 소멸 여부나 보상 G의 표시 조건은 네이티브 코드가 정합니다. 레이아웃 변경으로 보상·설치·수익 상태를 수정하지 않습니다.

조명의 현재 색·편집 색·밝기, 정밀 입력, 기본값, 켜기/끄기, 장면 확인, 취소·적용은 기존 네이티브 바인딩을 사용합니다. 색상 견본의 Designer 기본색은 런타임 값이 아닙니다.

웹 카드는 네이티브 스냅샷을 표시하고 선택·즐겨찾기 요청을 전달합니다. 가로 끌기·관성, 끌기 이후 클릭 차단, 도감 지정 카드 이동과 포커스 복구는 JavaScript 동작입니다. 상위 필터·검색·매출 순위·도감 버튼은 UMG에서 유지합니다.

실제 시설 아이콘·썸네일·이름·가격·수치와 기존 입력 바인딩을 보존합니다. Shared/**, Catalog/Legacy/**, 외부 공유 폰트·아이콘 및 다른 팀원 UI는 편집·저장 대상에 추가하지 않습니다.
